### 二、视图更新 (views_cost_sub_modules.py)

#### 1. 列表视图更新
**当前查询**:
```python
queryset = CostTaskPlan.objects.all()
if search_key:
    queryset = queryset.filter(project_code__icontains=search_key)
```

**更新为**:
```python
queryset = CostTaskPlan.objects.select_related('project').all()
if search_key:
    queryset = queryset.filter(
        Q(project__project_code__icontains=search_key) |
        Q(project__project_name__icontains=search_key)
    )
```

**关键点**:
- 使用 `select_related('project')` 优化查询性能
- 搜索时使用 `project__project_code` 而不是直接 `project_code`
- 排序时可使用 `project__project_code` 或保留本地字段

#### 2. 新增视图更新
**当前代码**:
```python
def cost_task_plan_add(request):
    if request.method == 'POST':
        form = CostTaskPlanForm(request.POST)
        if form.is_valid():
            obj = form.save(commit=False)
            if hasattr(request, 'tenant') and request.tenant:
                obj.tenant = request.tenant
            obj.save()
```

**更新为**:
```python
def cost_task_plan_add(request):
    if request.method == 'POST':
        form = CostTaskPlanForm(request.POST)
        if form.is_valid():
            obj = form.save(commit=False)
            if hasattr(request, 'tenant') and request.tenant:
                obj.tenant = request.tenant
            
            # 自动同步项目信息到冗余字段
            if obj.project:
                obj.project_code = obj.project.project_code
                obj.project_name = obj.project.project_name
                obj.project_type = obj.project.project_type
            
            obj.save()
            messages.success(request, '任务计划创建成功！')
            return redirect('cost_task_plan_list')
    else:
        form = CostTaskPlanForm()
    
    # 提供项目选择列表
    projects = CostProjectInfo.objects.filter(tenant=request.tenant).order_by('-created_at')
    
    context = {
        'form': form,
        'projects': projects,
    }
    return render(request, 'cost_consulting/task_plan/form.html', context)
```

### 四、JavaScript增强（可选但推荐）

#### 1. 项目选择自动填充
在表单页面添加JavaScript，当用户选择项目时自动填充冗余字段：

```javascript
document.addEventListener('DOMContentLoaded', function() {
    const projectSelect = document.getElementById('{{ form.project.id_for_label }}');
    const projectCodeInput = document.getElementById('{{ form.project_code.id_for_label }}');
    const projectNameInput = document.getElementById('{{ form.project_name.id_for_label }}');
    const projectTypeSelect = document.getElementById('{{ form.project_type.id_for_label }}');
    
    if (projectSelect) {
        projectSelect.addEventListener('change', function() {
            const projectId = this.value;
            if (projectId) {
                // AJAX请求获取项目信息
                fetch(`/api/cost-project-info/${projectId}/`)
                    .then(response => response.json())
                    .then(data => {
                        projectCodeInput.value = data.project_code;
                        projectNameInput.value = data.project_name;
                        projectTypeSelect.value = data.project_type;
                    })
                    .catch(error => console.error('Error:', error));
            }
        });
    }
});
```
