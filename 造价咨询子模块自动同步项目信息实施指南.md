**示例**（以cost_task_implementation_edit为例）：

```python
@login_required
def cost_task_implementation_edit(request, pk):
    """编辑任务实施"""
    obj = get_object_or_404(CostTaskImplementation, pk=pk)
    
    if request.method == 'POST':
        form = CostTaskImplementationForm(request.POST, instance=obj)
        if form.is_valid():
            updated_obj = form.save(commit=False)
            
            # 自动同步项目信息到冗余字段
            if updated_obj.project:
                updated_obj.project_code = updated_obj.project.project_code
                updated_obj.project_name = updated_obj.project.project_name
                updated_obj.project_type = updated_obj.project.project_type
            
            updated_obj.save()
            messages.success(request, '✓ 任务实施更新成功！')
            return redirect('eims_app:cost_task_implementation_list')
        else:
            for field, errors in form.errors.items():
                for error in errors:
                    messages.error(request, f'{field}: {error}')
    else:
        form = CostTaskImplementationForm(instance=obj)
    
    context = {'form': form, 'object': obj, 'title': '编辑任务实施', 'action': 'edit'}
    return render(request, 'cost_consulting/task_implementation/form.html', context)
```

**B. 在模板末尾添加JavaScript代码**

```html
<script>
document.addEventListener('DOMContentLoaded', function() {
    const projectSelect = document.getElementById('{{ form.project.id_for_label }}');
    const projectCodeInput = document.getElementById('{{ form.project_code.id_for_label }}');
    const projectNameInput = document.getElementById('{{ form.project_name.id_for_label }}');
    const projectTypeSelect = document.getElementById('{{ form.project_type.id_for_label }}');
    
    if (projectSelect) {
        projectSelect.addEventListener('change', function() {
            const projectId = this.value;
            if (projectId) {
                // 显示加载提示
                projectCodeInput.value = '加载中...';
                projectNameInput.value = '加载中...';
                
                // AJAX请求获取项目信息
                fetch(`/api/cost-project-info/${projectId}/`)
                    .then(response => response.json())
                    .then(data => {
                        if (data.success) {
                            projectCodeInput.value = data.project_code || '';
                            projectNameInput.value = data.project_name || '';
                            projectTypeSelect.value = data.project_type || '';
                        } else {
                            alert('获取项目信息失败：' + (data.error || '未知错误'));
                        }
                    })
                    .catch(error => {
                        console.error('Error:', error);
                        alert('网络错误，请稍后重试');
                    });
            } else {
                // 清空字段
                projectCodeInput.value = '';
                projectNameInput.value = '';
                projectTypeSelect.value = '';
            }
        });
    }
});
</script>
```

## 🎯 快速批量更新脚本（可选）

如果需要快速为所有子模块添加相同的逻辑，可以运行以下Python脚本：

```python
# update_all_cost_views.py
import re

# 需要更新的视图函数列表
views_to_update = [
    ('cost_task_implementation_add', 'CostTaskImplementation'),
    ('cost_task_implementation_edit', 'CostTaskImplementation'),
    ('cost_review_result_add', 'CostReviewResult'),
    ('cost_review_result_edit', 'CostReviewResult'),
    ('cost_payment_status_add', 'CostPaymentStatus'),
    ('cost_payment_status_edit', 'CostPaymentStatus'),
    ('cost_project_archive_add', 'CostProjectArchive'),
    ('cost_project_archive_edit', 'CostProjectArchive'),
    ('cost_remuneration_distribution_add', 'CostRemunerationDistribution'),
    ('cost_remuneration_distribution_edit', 'CostRemunerationDistribution'),
]

# 读取视图文件
with open('eims_app/views/views_cost_sub_modules.py', 'r', encoding='utf-8') as f:
    content = f.read()

# 为每个视图函数添加自动同步逻辑
for func_name, model_name in views_to_update:
    # 查找函数定义
    pattern = rf'(def {func_name}\(.*?\):.*?)(obj = form\.save\(commit=False\))'
    
    replacement = r'\1\2\n            \n            # 自动同步项目信息到冗余字段\n            if obj.project:\n                obj.project_code = obj.project.project_code\n                obj.project_name = obj.project.project_name\n                obj.project_type = obj.project.project_type'
    
    content = re.sub(pattern, replacement, content, flags=re.DOTALL)

# 写回文件
with open('eims_app/views/views_cost_sub_modules.py', 'w', encoding='utf-8') as f:
    f.write(content)

print("✓ 所有视图函数已更新")
```

## 🔧 故障排除

### 问题1: 选择项目后没有自动填充
**原因**: JavaScript代码未正确加载或API路径错误
**解决**: 
- 打开浏览器开发者工具（F12）
- 查看Console是否有错误
- 检查Network标签中API请求是否成功

### 问题2: 保存后冗余字段为空
**原因**: 视图代码未添加自动同步逻辑
**解决**: 检查视图函数中是否有自动同步代码

### 问题3: 表单中没有project选择器
**原因**: 模板未更新或Form类未包含project字段
**解决**: 
- 检查模板中是否有 `{{ form.project }}`
- 检查Form类的Meta.widgets中是否有project字段
