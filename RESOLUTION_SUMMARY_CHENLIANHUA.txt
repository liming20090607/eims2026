TECHNICAL NOTES
================================================================================

Multi-Tenant Architecture:
- Single Django application serving multiple companies
- Each company has URL path prefix: /{company_code}/
- Templates must use {% url %} tags to generate correct URLs
- Hardcoded absolute paths break tenant isolation

URL Pattern Used:
'{% url "eims_app:view_name" 0 %}'.replace('/0/', `/${dynamicId}/`)

This pattern:
1. Generates base URL with placeholder ID (0)
2. Replaces placeholder with actual dynamic ID
3. Ensures correct tenant prefix is included
4. Works across all tenant namespaces

Personnel vs User Models:
- Personnel: HR records (name, department, position, etc.)
- User: Authentication accounts (username, password, permissions)
- UserProfile: Links User to Tenant and stores additional user info
- Having a Personnel record does NOT automatically create a User account
- Must explicitly create User account for login capability
