## 🎯 交互规范

### 左键单击表头
- **功能**: 升序/降序排序切换
- **效果**: 
  - 第一次点击：升序排列 ▲
  - 第二次点击：降序排列 ▼
  - 第三次点击：取消排序

### 右键单击表头
- **功能**: 显示快捷菜单
- **菜单选项**:
  1. 🔼 升序排列
  2. 🔽 降序排列
  3. ❌ 取消排序
  4. ──────────────
  5. 🔽 筛选此列
  6. 🗑️ 清除筛选

### 筛选弹窗
- **标题**: 渐变紫色背景，显示"筛选: [字段名]"
- **输入框**: 大号输入框，支持模糊匹配
- **按钮**:
  - ❌ **取消**: 关闭弹窗，不应用筛选
  - ✅ **应用**: 应用筛选但保持弹窗打开（**只在有输入时可用**）
  - ✅✅ **确定**: 应用筛选并关闭弹窗

### JavaScript核心函数
```javascript
/**
 * 打开筛选弹窗
 */
function openFilterModal(field, label) {
    window.currentFilterField = field;
    window.currentFilterLabel = label;
    
    const urlParams = new URLSearchParams(window.location.search);
    const currentFilterValue = urlParams.get('filter_' + field) || '';
    
    document.getElementById('filterModalTitle').textContent = '筛选: ' + label;
    document.getElementById('filterFieldLabel').textContent = label + '包含:';
    document.getElementById('filterInput').value = currentFilterValue;
    document.getElementById('filterInput').placeholder = '请输入' + label + '关键词...';
    
    updateApplyButtonState();
    
    const modal = new bootstrap.Modal(document.getElementById('filterModal'));
    modal.show();
    
    setTimeout(() => {
        document.getElementById('filterInput').focus();
    }, 300);
}

/**
 * 更新"应用"按钮状态
 */
function updateApplyButtonState() {
    const applyBtn = document.getElementById('applyFilterBtn');
    const inputValue = document.getElementById('filterInput').value.trim();
    
    if (inputValue) {
        applyBtn.disabled = false;
        applyBtn.style.opacity = '1';
        applyBtn.style.cursor = 'pointer';
    } else {
        applyBtn.disabled = true;
        applyBtn.style.opacity = '0.5';
        applyBtn.style.cursor = 'not-allowed';
    }
}

/**
 * 应用筛选
 */
function applyFilter(closeModal = true) {
    const field = window.currentFilterField;
    const value = document.getElementById('filterInput').value.trim();
    
    if (!field) return;
    
    const url = new URL(window.location.href);
    
    if (value) {
        url.searchParams.set('filter_' + field, value);
    } else {
        url.searchParams.delete('filter_' + field);
    }
    
    url.searchParams.set('page', '1');
    window.location.href = url.toString();
    
    if (closeModal) {
        const modalEl = document.getElementById('filterModal');
        const modal = bootstrap.Modal.getInstance(modalEl);
        if (modal) modal.hide();
    }
}

/**
 * 取消筛选
 */
function cancelFilter() {
    const modalEl = document.getElementById('filterModal');
    const modal = bootstrap.Modal.getInstance(modalEl);
    if (modal) modal.hide();
}

/**
 * 清除筛选
 */
function clearFieldFilter() {
    const field = window.currentFilterField;
    if (!field) return;
    
    const url = new URL(window.location.href);
    url.searchParams.delete('filter_' + field);
    url.searchParams.set('page', '1');
    window.location.href = url.toString();
}
```
