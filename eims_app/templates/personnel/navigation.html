    快速操作指南
    添加新员工

    进入人员花名册 → 点击"添加人员" → 填写完整信息 → 保存

    分配部门

    进入可视化分配 → 选择人员 → 点击"分配到部门" → 选择部门 → 确认

    分配项目

    进入可视化分配 → 选择人员 → 点击"分配到项目" → 选择项目和岗位 → 确认

    添加证书

    进入人员证书 → 点击"添加证书" → 选择人员和证书信息 → 上传附件 → 保存

    召回人员

    进入可视化分配 → 在右侧找到已分配人员 → 点击"召回" → 确认

    查看统计

    各模块首页均有统计卡片，显示总人数、在岗人数、证书数量等关键指标
