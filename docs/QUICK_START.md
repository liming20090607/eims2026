# 文档管理快速指南

## 📚 文档目录位置

所有文档都存放在项目根目录的 **`docs/`** 文件夹中。

```

└── docs/                    ← 所有说明文档都在这里
    ├── README.md            ← 总索引（先读这个）
    ├── 01-项目文档/
    ├── 02-功能说明/
    ├── 03-部署指南/

```

## 🔍 如何快速找到文档

### 方法 1：打开总索引（推荐）
直接打开 **`docs/README.md`**，里面有完整的分类目录和查找指南。

1. 进入 `E:\EIMS2026\docs\`
2. 根据文档类型进入对应子目录
3. 使用右上角搜索框搜索关键词

### 方法 3：命令行搜索
```powershell
# 在项目根目录执行
cd docs
dir /s *.md | findstr "关键词"
```

## ➕ 新增文档操作流程

### 步骤 1：创建文档
在项目根目录创建新的 `.md` 文件：
```
my_new_feature.md
```

### 步骤 2：确定分类
根据内容判断所属分类：
- 新功能说明 → `02-功能说明/`
- Bug 修复 → `04-问题修复/`
- 性能优化 → `05-优化记录/`
- 使用教程 → `07-快速指南/`

### 步骤 3：移动文档
使用 PowerShell 命令移动：
```powershell
# 示例：移动到功能说明目录
move my_new_feature.md docs\02-功能说明\

# 示例：移动到问题修复目录
move bug_fix.md docs\04-问题修复\
```

### 步骤 4：更新索引（可选）
打开 `docs/README.md`，在对应分类下添加文档名称。

## 📋 文档管理最佳实践

### ✅ 推荐做法
1. **及时归档**：文档创建后立即移动到正确分类
2. **命名清晰**：使用描述性的文件名，如 `FEATURE_TYPE.md`
3. **保持更新**：功能变更时同步更新文档
4. **添加索引**：在 `README.md` 中记录重要文档

### ❌ 避免做法
1. 不要在根目录堆放大量文档
2. 不要使用模糊的文件名（如 `test.md`, `temp.md`）
3. 不要忘记归类，导致文档丢失
4. 不要删除历史版本文档（可标记为"已废弃"）
