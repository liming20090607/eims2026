🔧 解决 DataTables 列数错误

⚠️ 问题描述

您看到的错误提示：

DataTables warning: table id=project-table - Incorrect column count.

这是因为浏览器缓存了旧版本的页面，而新版本已经修复了列数问题。

🚀 最快解决方法（推荐）

在浏览器中打开项目列表页面，然后按：

Ctrl + Shift + Delete

或

Ctrl + F5

📋 详细解决步骤

1选择您的浏览器
Chrome / Edge
Firefox
Safari
2Chrome / Edge 清除缓存步骤
  • 按 Ctrl + Shift + Delete
  • 时间范围选择：全部时间
  • 勾选：
    • ✅ Cookie 及其他网站数据
    • ✅ 缓存的图片和文件
  • 点击"清除数据"按钮
  • 关闭浏览器
  • 重新打开浏览器
  • 访问：http://localhost:8000/projects/
2Firefox 清除缓存步骤
  • 按 Ctrl + Shift + Delete
  • 时间范围选择：全部
  • 勾选：
    • ✅ Cookie
    • ✅ 缓存
  • 点击"立即清除"按钮
  • 关闭浏览器
  • 重新打开浏览器
  • 访问：http://localhost:8000/projects/
2Safari 清除缓存步骤
  • 按 Command + Option + E
  • 或选择菜单：开发 → 清空缓存
  • 关闭浏览器
  • 重新打开浏览器
  • 访问：http://localhost:8000/projects/
3验证修复

清除缓存后，访问项目列表页面，应该：

  • ✅ 不再出现错误弹窗
  • ✅ 表格正常显示
  • ✅ 可以正常使用排序、分页、搜索功能
4使用无痕模式（备选方案）

如果以上方法都不行，可以尝试使用无痕模式：

  • Chrome/Edge: Ctrl + Shift + N
  • Firefox: Ctrl + Shift + P
  • Safari: Command + Shift + N

然后在无痕窗口中访问：http://localhost:8000/projects/

💡 技术说明

问题已修复：项目列表表格现在有 14 列（包括复选框和操作列），空数据提示的 colspan 也已从 13 改为 14。

为什么需要清除缓存：浏览器缓存了旧版本的 HTML 页面（13 列），而服务器返回的新版本是 14 列，DataTables 插件检测到不匹配所以报错。

服务器已重启，代码已修复，只需清除浏览器缓存即可！
