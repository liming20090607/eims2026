# 员工信息与项目人员分离管理说明

## 功能概述

为了更好地区分**员工基本信息**和**项目人员信息**，系统将原来的单一 Personnel 模型拆分为两个独立的模型：

### 1. Employee（员工信息）- 入职登记使用

用于记录员工的基本个人信息，员工入职时由人事部门登记。

**字段包括：**
- 员工编号 (employee_code)
- 姓名、性别、身份证号
- 籍贯、民族、学历
- 联系方式：手机号、固定电话、住址、微信
- 应急联系人、应急电话
- 职务信息：行政职务、技术职务、执业资格、职称、任职资格
- 入职时间、离职时间
- 备注

**访问路径：** 侧边栏 → 员工信息

**操作流程：**
1. 新员工入职时，在"员工信息"模块添加员工基本信息
2. 填写完整的个人信息和职务信息
3. 保存后，员工信息入库

### 2. Personnel（项目人员）- 二次分配使用

用于记录员工在项目中的分配情况，支持一个员工分配到多个项目。

**字段包括：**
- 人员编号 (personnel_code) - 从员工信息同步
- 姓名、性别 - 从员工信息同步
- 项目编号 (project_code)
- 所在项目 (project) - 关联 Project 模型
- 部门、岗位
- 手机号码、邮箱
- 入岗时间、离岗时间
- 备注

**访问路径：** 侧边栏 → 人员管理

**操作流程：**
1. 员工入职后，根据项目需要进行分配
2. 在"人员管理"模块添加项目人员记录
3. 选择对应的员工（可选，支持手动输入）
4. 填写项目相关信息（部门、岗位、入岗时间等）
5. 保存到具体项目中

## 数据关系

```
Employee (员工信息)
    ↓
    employee_code (一对多)
    ↓
Personnel (项目人员) → Project (项目)
```

- 一个员工可以有多个项目分配记录
- 每个项目分配记录包含该员工在特定项目的岗位信息
- 员工基本信息变更时，不影响已分配的项目记录

## 使用场景示例

### 场景 1：新员工入职
1. 人事在【员工信息】中添加新员工张三
2. 填写完整个人信息：身份证、学历、联系方式等
3. 保存后，张三是公司的正式员工

### 场景 2：员工分配到项目
1. 项目经理在【人员管理】中添加项目人员
2. 选择员工"张三"（系统自动带出基本信息）
3. 填写项目相关信息：部门=工程部，岗位=工程师，入岗时间=2026-03-21
4. 选择所在项目="XX 工程项目"
5. 保存后，张三被分配到该项目

### 场景 3：员工调动
1. 原项目：在【人员管理】中更新离岗时间
2. 新项目：在【人员管理】中添加新的项目分配记录
3. 员工基本信息保持不变

## 优势

1. **职责清晰**：人事管理 vs 项目管理
2. **数据复用**：员工基本信息只需录入一次
3. **灵活性高**：支持一个员工同时参与多个项目
4. **历史可追溯**：员工的项目调动记录完整保留
5. **统计方便**：可轻松统计员工参与的所有项目

## 注意事项

1. 建议先建立员工信息，再进行项目分配
2. 项目人员信息中的"人员编号"和"姓名"应与员工信息保持一致
3. 员工离职时，在【员工信息】中标记离职状态，项目分配可设置离岗时间
4. 超级管理员可以访问所有模块，普通用户根据权限访问
