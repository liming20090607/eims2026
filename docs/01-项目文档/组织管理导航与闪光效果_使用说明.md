## 💡 闪光效果技术要点

### 为什么需要 `position: relative`?

**原因**: CSS 伪元素 `::after` 使用 `position: absolute` 定位，需要一个相对定位的父元素作为参考点。

**修复前**:
```css
.nav-link {
    /* 没有 position: relative */
}

.nav-link::after {
    position: absolute;  /* ← 相对于最近的定位祖先元素 */
    /* 可能找不到正确的父元素 */
}
```

**修复后**:
```css
.nav-link {
    position: relative;  /* ← 为 ::after 提供定位参考 */
}

.nav-link::after {
    position: absolute;  /* ← 现在相对于 .nav-link 定位 */
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
}
```

---

### 为什么要 `overflow: hidden`?

**原因**: 闪光效果从 `-100%` 开始，到`+100%` 结束，如果没有限制，会在按钮外看到闪光。

**效果**:
```css
.nav-item {
    position: relative;
    overflow: hidden;  /* ← 隐藏超出边界的闪光 */
}
```

---

### 渐变参数的优化

**优化前**:
```css
background: linear-gradient(
    90deg, 
    rgba(255,255,255,0.1) 0%,      /* 太淡，几乎看不见 */
    rgba(255,255,255,0) 100%       
);
```

**优化后**:
```css
background: linear-gradient(
    90deg, 
    rgba(255,255,255,0) 0%,        /* 从透明开始 */
    rgba(255,255,255,0.3) 50%,     /* 中间达到 30% 亮度 */
    rgba(255,255,255,0) 100%       /* 回到透明 */
);
```

**优势**:
- ✅ 三段式渐变，形成明显的光带
- ✅ 中间最亮 (30%),向两边逐渐消失
- ✅ 视觉效果更加优雅和明显
