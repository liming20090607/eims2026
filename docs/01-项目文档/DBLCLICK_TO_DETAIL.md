# ✅ 双击查看详情功能已实现

## 🎯 功能说明

在项目台账列表页面，**双击任意一行**即可跳转到该项目的详情页面，查看完整的项目信息以及三个子窗体（项目动态、产值回款、项目人员）。

---

## 📁 修改的文件

### **文件**: [`project_ledger/list.html`](file://e:\EIMS2026\eims_app\templates\project_ledger\list.html#L325-L331)

**修改内容**:
```html
<!-- 之前：单击选择项目 -->
<tr class="clickable-row" onclick="selectProject({{ item.pk }})">

<!-- 现在：双击跳转到详情页 -->
<tr class="clickable-row" 
    ondblclick="window.location.href='{% url 'eims_app:project_ledger_detail' item.pk %}'"
    title="双击查看详情">
```

---

## 🚀 使用方法

### **方法 1: 双击行**（推荐）⭐

1. 打开项目台账列表
   ```
   http://localhost:8000/project-ledger/
   ```

2. 找到要查看的项目

3. **双击该项目的任意一行**

4. 自动跳转到项目详情页
   ```
   http://localhost:8000/project-ledger/{项目 ID}/detail/
   ```

5. 查看完整的 project 信息和三个子窗体：
   - 📊 项目动态
   - 💰 产值回款
   - 👥 项目人员

---

### **方法 2: 点击"查看"按钮**（传统方式）

在操作列点击"查看"图标（眼睛形状），同样可以跳转到详情页。

## 🆘 故障排查

### **问题 1: 双击没反应**

**可能原因**:
1. 浏览器不支持（极少见）
2. JavaScript 被禁用
3. 缓存问题

**解决方法**:
```
1. 按 Ctrl+F5 硬刷新
2. 清除浏览器缓存
3. 尝试无痕模式
```

---

### **问题 2: 双击变成选中**

**原因**: 单击事件优先级更高

**解决**: 确保双击速度够快，不要慢速点击两次

---

### **问题 3: 跳转 404**

**原因**: URL 配置错误

**检查**:
```python
# eims_app/urls.py 应该有：
path('project-ledger/<int:pk>/detail/', 
     views.project_ledger_detail, 
     name='project_ledger_detail'),
```
