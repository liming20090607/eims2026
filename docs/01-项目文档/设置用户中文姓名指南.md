# 设置用户中文姓名指南

## 📋 概述

系统已配置支持**拼音用户名**和**中文姓名**双重登录方式。用户可以使用以下任一方式登录：
- 拼音用户名（如：`zhangsan`）+ 密码
- 中文姓名（如：`张三`）+ 密码

本指南介绍如何为后台用户设置中文姓名。

---

## 🔧 方法一：通过 Django Admin 后台设置（推荐）

### 步骤：

1. **登录 Django Admin 后台**
   - 访问：`http://localhost:8000/admin/`
   - 使用管理员账号登录

2. **进入用户资料管理**
   - 在首页找到并点击 **"用户资料"** 模块

3. **选择要编辑的用户**
   - 在用户列表中找到目标用户
   - 点击该用户进入编辑页面

4. **设置中文姓名**
   - 在 **"基本信息"** 区域找到 **"姓名"** 字段
   - 输入中文姓名（如：张三）
   - 可选：填写性别、生日、电话、微信等信息

5. **保存**
   - 点击页面底部的 **"保存"** 按钮

6. **验证**
   - 设置完成后，该用户即可使用中文姓名登录

## 📝 方法三：直接在 Django Shell 中设置

### 进入 Django Shell：
```bash
cd e:\EIMS2026
python manage.py shell
```

### 执行代码：

#### 设置单个用户：
```python
from django.contrib.auth.models import User
from eims_app.models.model_user import UserProfile

user = User.objects.get(username='zhangsan')
profile, created = UserProfile.objects.get_or_create(user=user)
profile.real_name = '张三'
profile.save()
print(f"✓ 已为用户 {user.username} 设置中文姓名：张三")
```

#### 批量设置：
```python
from django.contrib.auth.models import User
from eims_app.models.model_user import UserProfile

name_mapping = {
    'zhangsan': '张三',
    'lisi': '李四',
    'wangwu': '王五',
}

for username, chinese_name in name_mapping.items():
    user = User.objects.get(username=username)
    profile, _ = UserProfile.objects.get_or_create(user=user)
    profile.real_name = chinese_name
    profile.save()
    print(f"✓ {username} → {chinese_name}")
```

## 🎯 常见问题

### Q1: 设置后无法用中文姓名登录？
**A:** 请检查：
1. 确认已在 Admin 后台保存了中文姓名
2. 确认密码正确
3. 检查 `settings.py` 中是否已配置自定义认证后端

### Q2: 一个用户可以有多个名字吗？
**A:** 不可以。每个用户只有一个 `real_name` 字段。如果需要支持别名，需要扩展模型。

### Q3: 忘记某个用户的中文姓名了怎么办？
**A:** 运行查看脚本：
```bash
python manage.py shell < manage_user_names.py
```

### Q4: 可以修改已设置的中文姓名吗？
**A:** 可以。在 Admin 后台重新编辑该用户，修改姓名后保存即可。
