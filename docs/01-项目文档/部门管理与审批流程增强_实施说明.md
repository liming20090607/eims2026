# 部门管理与审批流程增强系统 - 实施说明

## 📋 已完成的功能

### 一、核心模型（3 个）

#### 1. Department（部门管理）
**文件**: `eims_app/models/model_department.py`

**功能特性**:
- ✅ 部门编号、名称、类型（职能/项目/临时）
- ✅ 上级部门（支持多级层级）
- ✅ 部门负责人、联系方式
- ✅ 部门职能描述
- ✅ 部门状态（正常/停用/合并中）
- ✅ 成立日期、排序顺序

**关键字段**:
```python
department_code      # 唯一部门标识
department_name      # 部门全称
department_type      # 职能部门/项目部门/临时部门
parent_department    # 上级部门（支持树形结构）
manager_name         # 部门负责人姓名
contact_phone/email  # 联系方式
description          # 部门描述
responsibilities     # 详细职能说明
member_count         # 属性：自动统计部门人数
```

#### 2. DepartmentRole（部门角色配置）
**功能特性**:
- ✅ 部门内角色分配（经理/副职/主管/成员/助理）
- ✅ 用户与角色关联
- ✅ 主要负责人标记
- ✅ 权限列表配置

**角色类型**:
```python
manager     # 部门经理
deputy      # 部门副职
supervisor  # 主管
member      # 普通成员
assistant   # 助理
```

#### 3. ApprovalChain（审批链配置）
**功能特性**:
- ✅ 支持逐级审批（三级审批）
- ✅ 支持并行审批
- ✅ 支持混合审批
- ✅ 跨部门协同审批
- ✅ 业务类型分类

**审批级别**:
```python
level_1: 一级审批部门 + 审批角色（如：部门经理）
level_2: 二级审批部门 + 审批角色（如：分管领导）
level_3: 三级审批部门 + 审批角色（如：总经理）
```

**业务类型**:
```python
personnel_allocate  # 人员分配
personnel_transfer  # 人员调动
leave_apply         # 请假申请
expense_apply       # 费用报销
contract_sign       # 合同签订
payment_apply       # 付款申请
other              # 其他
```

## 📊 数据库表结构

### Department 表
```sql
CREATE TABLE eims_app_department (
    id INTEGER PRIMARY KEY,
    department_code VARCHAR(50) UNIQUE NOT NULL,
    department_name VARCHAR(100) NOT NULL,
    department_type VARCHAR(20),
    parent_department_id INTEGER,  -- 自引用外键
    manager_id INTEGER,            -- User 外键
    manager_name VARCHAR(50),
    contact_phone VARCHAR(20),
    contact_email VARCHAR(254),
    description TEXT,
    responsibilities TEXT,
    status VARCHAR(20),
    established_date DATE,
    order INTEGER,
    is_deleted BOOLEAN DEFAULT FALSE,
    create_time DATETIME,
    update_time DATETIME
);
```

### DepartmentRole 表
```sql
CREATE TABLE eims_app_department_role (
    id INTEGER PRIMARY KEY,
    department_id INTEGER NOT NULL,    -- Department 外键
    user_id INTEGER NOT NULL,          -- User 外键
    role_type VARCHAR(20),
    role_name VARCHAR(50),
    is_primary BOOLEAN DEFAULT FALSE,
    permissions TEXT,
    is_deleted BOOLEAN DEFAULT FALSE,
    create_time DATETIME,
    update_time DATETIME,
    UNIQUE(department_id, user_id, role_type)
);
```

### ApprovalChain 表
```sql
CREATE TABLE eims_app_approval_chain (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100),
    business_type VARCHAR(30),
    chain_type VARCHAR(20),
    level_1_department_id INTEGER,
    level_1_role VARCHAR(50),
    level_2_department_id INTEGER,
    level_2_role VARCHAR(50),
    level_3_department_id INTEGER,
    level_3_role VARCHAR(50),
    need_cross_department BOOLEAN,
    is_active BOOLEAN DEFAULT TRUE,
    is_deleted BOOLEAN DEFAULT FALSE,
    create_time DATETIME,
    update_time DATETIME
);
```
