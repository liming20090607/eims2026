# ✅ 项目详情窗体命名优化完成

## 🐛 问题描述

项目管理模块下有两个"项目详情"窗体，容易混淆：

1. **列表页右侧的详情面板** - 显示简略信息
2. **独立的完整详情页** - 显示完整信息和三个子窗体

用户不清楚两者的区别，也不知道应该使用哪个。

---

## ✅ 解决方案

### **1. 重命名区分**

#### **列表页右侧面板**
**原名**: "项目详情"  
**新名**: "👁️ 项目概览"

**特点**:
- 👁️ 使用眼睛图标（`bi-eye`）
- 📋 只显示基本信息（6 个字段）
- ➕ 新增"完整详情"按钮

---

#### **独立详情页**
**原名**: "项目详情"  
**新名**: "📘 项目完整详情"

**特点**:
- 📘 标题包含"（完整详情）"标识
- 📊 显示所有字段（6 个卡片）
- 🔗 包含三个子窗体（项目动态、产值回款、项目人员）

---

### **2. 视觉增强**

#### **列表页：项目概览**

**修改内容**:
```html
<!-- 之前 -->
<h4><i class="bi bi-journal-text me-2"></i>项目详情</h4>

<!-- 现在 -->
<h4><i class="bi bi-eye me-2"></i>项目概览</h4>
<a href="..." class="btn btn-sm btn-info">
    <i class="bi bi-box-arrow-up-right me-1"></i>完整详情
</a>
```

**效果**:
- ✅ 图标从书本（journal-text）改为眼睛（eye）
- ✅ 标题从"详情"改为"概览"
- ✅ 新增快捷按钮跳转到完整详情页

---

#### **独立页：项目完整详情**

**修改内容**:
```html
<!-- 之前 -->
<h2>{{ project_detail.project_name }}</h2>

<!-- 现在 -->
<h2>
    {{ project_detail.project_name }}
    <small class="text-muted">（完整详情）</small>
</h2>
```

**页面标题**:
```
之前：项目名称 - 项目详情
现在：项目名称 - 项目完整详情
```

## 🚀 使用场景

### **使用"项目概览"的场景**

1. **快速浏览** - 在列表中查看某个项目的关键信息
2. **对比多个项目** - 点击不同行，快速切换查看
3. **初步筛选** - 判断是否需要查看完整详情

**操作方式**:
```
1. 在项目台账列表中单击某一行
2. 右侧自动显示该项目的概览信息
3. 如需更多信息，点击"完整详情"按钮
```

---

### **使用"项目完整详情"的场景**

1. **详细查看** - 需要查看项目的所有信息
2. **管理子记录** - 添加/编辑项目动态、产值回款、项目人员
3. **打印输出** - 需要打印完整的项目资料

**操作方式**:
```
方式 1: 双击列表中的某一行
方式 2: 点击"项目概览"面板中的"完整详情"按钮
方式 3: 点击列表中的"查看"按钮（眼睛图标）
```

## 💡 设计理念

### **为什么这样设计？**

1. **信息层次清晰** - 概览 vs 详情，各司其职
2. **渐进式披露** - 先看概要，再根据需要查看完整信息
3. **减少认知负担** - 不会同时面对大量信息
4. **操作路径明确** - 从概览到详情的自然流程

---

### **图标选择的考量**

| 图标 | 含义 | 使用场景 |
|------|------|---------|
| 👁️ `bi-eye` | 查看、概览 | 项目概览面板 |
| 📘 `bi-journal-text` | 记录、档案 | 项目完整详情页 |
| 🔗 `bi-box-arrow-up-right` | 跳转、外链 | 完整详情按钮 |
