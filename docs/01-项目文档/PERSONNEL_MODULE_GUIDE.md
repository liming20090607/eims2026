- 支持 Excel (.xlsx) 格式
- 最大支持 10MB 文件
- 自动识别表头

### 5. 导出功能
- 支持选中导出或全部导出
- Excel 格式 (.xlsx)
- 包含所有人员信息字段
- 自动关联项目名称

## 二、人员数据结构

### 必需字段
- **人员编号**：唯一标识符
- **姓名**：人员姓名

### 基本字段
- **性别**：男 (0) / 女 (1) / 其他 (2)
- **岗位**：工作岗位
- **手机号码**：联系电话
- **部门**：所属部门

### 扩展字段
- **项目编号**：关联到具体项目
- **入岗时间**：入职日期
- **离岗时间**：离职日期
- **邮箱**：电子邮箱
- **备注**：其他说明

## 三、使用步骤

### 1. 导入现有人员信息

#### 第一步：下载模板
1. 访问人员管理页面：http://localhost:8000/personnel/
2. 点击"导入"按钮
3. 点击"下载模板"链接
4. 保存 `人员导入模板.xlsx` 文件

#### 第二步：准备数据
打开模板文件，按照示例填写人员信息：

| 人员编号 | 姓名 | 性别 | 岗位 | 手机号码 | 部门 | 项目编号 | 入岗时间 | 离岗时间 | 邮箱 | 备注 |
|---------|------|------|------|---------|------|---------|---------|---------|------|------|
| PER001 | 张三 | 男 | 项目经理 | 13800138001 | 工程部 | PJ2026001 | 2026-01-01 | | zhangsan@example.com | |
| PER002 | 李四 | 女 | 技术负责人 | 13800138002 | 技术部 | PJ2026001 | 2026-01-05 | | lisi@example.com | |

**注意事项：**
- 人员编号必须唯一
- 姓名不能为空
- 性别填写：男、女、其他
- 日期格式：YYYY-MM-DD
- 项目编号必须是系统中已存在的项目

#### 第三步：上传导入
1. 回到人员管理页面
2. 点击"导入"按钮
3. 选择准备好的 Excel 文件
4. 点击"导入"
5. 等待导入完成，查看导入结果

### 2. 手动添加人员

1. 点击"添加人员"按钮
2. 填写人员信息表单
3. 点击"提交"
4. 系统提示添加成功

### 3. 编辑人员信息

1. 在人员列表中找到要编辑的人员
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"提交"保存修改

### 4. 导出人员信息

#### 导出全部
1. 直接点击"导出"按钮
2. 下载 `人员信息表_YYYYMMDD_HHMMSS.xlsx` 文件

#### 导出选中
1. 勾选要导出的人员
2. 点击"导出"按钮
3. 仅导出选中的记录

## 七、常见问题

### Q1: 导入失败怎么办？
A: 检查以下几点：
- 文件格式是否为 .xlsx
- 文件大小是否超过 10MB
- 是否包含必需的表头（人员编号、姓名）
- 数据格式是否正确
- 查看错误提示信息

### Q2: 人员编号重复怎么办？
A: 系统会根据人员编号自动更新已存在的人员信息，不会创建重复记录。

### Q3: 如何删除人员？
A: 
- 单个删除：点击"删除"按钮
- 批量删除：勾选多个人员后点击"批量删除"
- 删除采用软删除方式，数据不会真正从数据库清除

### Q4: 如何查看某个项目的所有人员？
A: 在人员列表页面，使用"项目"筛选下拉框选择对应项目即可。

### Q5: 导出的文件用什么打开？
A: 使用 Microsoft Excel、WPS 表格或其他支持 .xlsx 格式的软件打开。
