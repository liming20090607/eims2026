### 5. ✅ 权限控制功能

#### 创建的权限检查工具

**文件**: `eims_app/templatetags/permission_tags.py`

提供两个模板标签：

##### (1) `{% check_permission '权限代码' as 变量 %}`

检查用户是否有指定权限

**用法**:
```django
{% load permission_tags %}
{% check_permission 'eims_app.view_department' as has_perm %}

{% if has_perm %}
    <!-- 显示按钮 -->
{% else %}
    <!-- 显示无权限提示 -->
{% endif %}
```

##### (2) `{% has_module_permission '模块名' as 变量 %}`

检查用户对模块的访问级别

**返回值**:
- `'full'`: 完全访问（有编辑权限）
- `'readonly'`: 只读访问（仅有查看权限）
- `'none'`: 无权限

**用法**:
```django
{% has_module_permission 'department' as access_level %}

{% if access_level == 'full' %}
    <!-- 完全访问：显示所有操作按钮 -->
{% elif access_level == 'readonly' %}
    <!-- 只读访问：仅显示查看按钮，禁用编辑删除 -->
{% else %}
    <!-- 无权限：禁用或隐藏 -->
{% endif %}
```

## 🚀 使用方法

### 方法一：在模板中检查权限

#### 示例 1：根据权限显示按钮
```django
{% load permission_tags %}

<!-- 检查删除权限 -->
{% check_permission 'eims_app.delete_department' as can_delete %}

{% if can_delete %}
    <button class="btn btn-danger">删除</button>
{% else %}
    <button class="btn btn-secondary" disabled title="需管理员授权">删除</button>
{% endif %}
```

#### 示例 2：根据访问级别禁用菜单
```django
{% load permission_tags %}

{% has_module_permission 'department' as dept_access %}

<li class="nav-item">
    {% if dept_access == 'none' %}
        <!-- 无权限：显示为淡色，不可点击 -->
        <a href="#" class="nav-link disabled text-muted">
            <i class="bi bi-building"></i> 部门管理
        </a>
    {% else %}
        <!-- 有权限：正常显示 -->
        <a href="{% url 'eims_app:department_list' %}" class="nav-link">
            <i class="bi bi-building"></i> 部门管理
        </a>
    {% endif %}
</li>
```

---

### 方法二：在视图中使用装饰器

#### 示例 1：部门列表（需要查看权限）

    # 普通用户会看到"权限不足"弹窗

## ⚙️ 如何在 Django Admin 中设置权限

### 步骤 1：访问权限管理

1. 登录 Django Admin: `http://localhost:8000/admin/`
2. 进入"身份验证和授权" → "权限"
3. 找到"eims_app"应用

### 步骤 2：查看现有权限

Django 自动为每个 Model 生成 4 个权限：
- `Can view xxx` - 查看权限
- `Can add xxx` - 添加权限
- `Can change xxx` - 编辑权限
- `Can delete xxx` - 删除权限

### 步骤 3：给用户分配权限

1. 进入"用户"列表
2. 选择要编辑的用户
3. 在"用户权限"部分添加相应权限
4. 保存

### 步骤 4：或使用组管理（推荐）

1. 进入"组"列表
2. 创建新组（如"部门管理员"）
3. 为该组添加权限：
   - Can view department
   - Can view departmentrole
   - Can view approvalchain
4. 将用户添加到该组

## 🔧 故障排查

### 问题 1：菜单都是淡色

**检查**:
1. 确认用户是否登录
2. 检查用户是否有权限
3. 查看浏览器控制台错误

**解决**:
```python
# 在 Django shell 中检查用户权限
from django.contrib.auth.models import User
user = User.objects.get(username='your_username')
print(user.get_all_permissions())
```

---

### 问题 2：弹窗不显示

**检查**:
1. 确认 `permission-check.js` 已加载
2. 打开浏览器控制台查看错误
3. 确认 Bootstrap 5 已加载

**解决**:
```html
<!-- 确保在 base.html 中包含 -->
<script src="{% static 'js/permission-check.js' %}"></script>
```

---

### 问题 3：权限标签不起作用

**检查**:
1. 确认 `permission_tags.py` 在正确的目录
2. 确认在模板中加载了标签库
3. 重启 Django 服务器

**解决**:
```django
<!-- 在模板顶部加载 -->
{% load permission_tags %}
```
