## 🔍 三个模块能做什么？

### 📋 人员花名册
**适合场景**：
- 入职新员工，需要录入信息
- 更新员工联系方式
- 查看某个部门的所有人员
- 导出员工名单做报表
- 批量导入员工信息

**典型操作**：
```
添加新员工 → 填写信息 → 保存到花名册
↓
分配到部门 → 分配到项目 → 完成！
```

---

### 🏆 人员证书
**适合场景**：
- 员工考取了新证书
- 证书到期需要提醒
- 查找某人的所有证书
- 统计持证人员数量
- 上传证书电子扫描件

**典型操作**：
```
选择员工 → 添加证书 → 填写证书信息 → 上传附件
↓
系统自动关联到该员工 → 完成！
```

---

### 👤 人员分配 / 可视化分配
**适合场景**：
- 新项目开工，需要组建团队
- 项目完工，人员需要调配
- 部门架构调整
- 批量调动多名员工
- 查看人员在哪些项目

**典型操作**（使用可视化分配）：
```
打开可视化分配页面
↓
勾选需要调动的员工（可多选）
↓
点击"分配到项目" → 选择项目和岗位
↓
确认 → 系统自动同步所有数据 → 完成！
```

## 💡 新手推荐操作流程

### 第一次使用？按这个顺序：

#### 步骤 1：访问模块导航
```
URL: http://localhost:8000/personnel/navigation/
```
了解三大功能的整体架构和关系。

#### 步骤 2：录入基础数据
```
进入：人员花名册 (/personnel/)

```

#### 步骤 3：尝试分配部门
```
进入：可视化分配 (/personnel/allocation-visual/)
操作：选择员工 → 分配到部门
```

#### 步骤 4：尝试分配项目
```
继续在：可视化分配
操作：选择员工 → 分配到项目
```

#### 步骤 5：添加证书
```
进入：人员证书 (/personnel/certificates/)
操作：为某员工添加一个证书
```

#### 步骤 6：验证数据同步
```
回到：人员花名册
查看：员工的项目信息是否已更新
```

## ❓ 找不到怎么办？

### 问题 1：侧边栏没有"人员管理"
**解决方法**：
1. 刷新页面（F5）
2. 清除浏览器缓存（Ctrl+Shift+Delete）
3. 确认已登录系统
4. 联系管理员确认权限

### 问题 2：点击后显示 404
**解决方法**：
1. 检查 URL 是否正确
2. 确认服务器正在运行
3. 重启 Django 服务：
   ```bash
   python manage.py runserver
   ```

### 问题 3：页面空白或报错
**解决方法**：
1. 按 F12 打开浏览器开发者工具
2. 查看 Console 中的错误信息
3. 截图并发给技术支持
