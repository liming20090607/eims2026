### 2. 权限检查装饰器系统 ✅

**文件**: `utils/permissions.py`

提供了三个强大的权限检查装饰器：

#### (1) `permission_required(permission_code)`
通用权限检查装饰器

**用法**:
```python
from utils.permissions import permission_required

@permission_required('eims_app.view_department')
def department_list(request):
    ...
```

**特性**:
- ✅ 自动检查用户是否登录
- ✅ 检查用户是否有指定权限
- ✅ 超级管理员自动拥有所有权限
- ✅ 未登录返回 401 JSON
- ✅ 权限不足返回 403 JSON

---

#### (2) `superuser_required()`
超级用户专用装饰器

**用法**:
```python
from utils.permissions import superuser_required

@superuser_required
def admin_dashboard(request):
    ...
```

**特性**:
- ✅ 仅允许超级管理员访问
- ✅ 普通用户返回 403 权限不足提示
- ✅ 未登录返回 401 未登录提示

---

#### (3) `ajax_permission_required(permission_code)`
专门用于 AJAX 请求的权限检查

**用法**:
```python
from utils.permissions import ajax_permission_required

@ajax_permission_required('eims_app.delete_department')
def delete_department_ajax(request):
    ...
```

**特性**:
- ✅ 专门处理 AJAX 请求
- ✅ 返回 JSON 格式错误信息
- ✅ 前端自动接收并处理

### 方法二：模板中直接使用

#### 按钮点击时检查权限
```html
<!-- 方法 1: 使用 onclick -->
<button onclick="checkPermissionAndAction()" class="btn btn-danger">
    删除部门
</button>

<script>
function checkPermissionAndAction() {
    // 可以通过 AJAX 检查权限
    fetch('/api/check-permission/', {
        method: 'POST',
        headers: {'X-CSRFToken': getCookie('csrftoken')}
    })
    .then(response => {
        if (response.status === 403) {
            showPermissionDenied(); // 显示权限不足弹窗
        } else {
            // 执行删除操作
        }
    });
}
</script>
```

```

         ↓
```

## ⚙️ 如何在 Django 中设置权限

### 步骤 1：创建权限（Django Admin）

1. 访问 `/admin/`
2. 进入"身份验证和授权" → "权限"
3. 找到 `eims_app` 应用
4. 查看/编辑权限

### 步骤 2：给用户分配权限

1. 访问 `/admin/auth/user/`
2. 选择用户
3. 在"用户权限"部分添加权限
4. 保存

### 步骤 3：或使用组管理

1. 访问 `/admin/auth/group/`
2. 创建组（如"部门管理员"）
3. 为组分配权限
4. 将用户添加到组
