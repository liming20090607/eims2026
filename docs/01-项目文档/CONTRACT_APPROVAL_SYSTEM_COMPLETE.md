## 🎯 核心功能

### **1. 数据模型**

#### **ContractApproval（合同审批表）**
存储审批主信息：
- 审批标题、合同名称、合同类别
- 合同金额、合同双方
- 申请部门、申请人
- 服务周期、服务到期时间
- 审批状态（草稿、待审核、审核中、已通过、已退回、已撤销）
- 审批结果（待签订、已签订、审批未通过）

#### **ContractAttachment（合同附件表）**
存储上传的文档：
- 文件上传（支持 PDF、DOC、DOCX、XLS、XLSX、JPG、PNG）
- 文件类型（合同文件、附件材料、其他资料）
- 自动记录文件名和大小

#### **ContractApprovalRecord（合同审批记录表）**
存储审批历史记录：
- 操作类型（提交、同意、退回、撤销、评论）
- 操作人、操作时间
- 审批意见

## 💡 业务流程

### **新增审批流程**

```
1. 用户点击"新增审批"
   ↓
2. 填写审批表单（标题、合同信息、金额等）
   ↓
3. 上传附件（合同文件、附件材料）
   ↓
4. 保存为草稿状态
   ↓
5. 可选择编辑或直接提交
```

---

### **审批提交流程**

```
1. 用户从草稿或已退回状态提交
   ↓
2. 状态变更为"待审核"
   ↓
3. 记录提交操作
   ↓
4. 等待管理员审批
```

---

### **审批操作流程**

```
管理员审批时：
┌─────────────────────┐
│ 1. 查看审批详情     │
│ 2. 预览附件         │
│ 3. 查看审批历史     │
│ 4. 选择操作：       │
│    - 同意 → 生成合同台账
│    - 退回 → 填写原因
└─────────────────────┘
```

### **自动生成合同台账**

**审批通过后自动执行**:

```python
# 生成合同台账记录
project_detail = ProjectDetail.objects.create(
    project_code="HT20260325153000",
    contract_code="HT-20260325-123",
    project_name=approval.contract_name,
    contract_category=approval.contract_category,
    contract_amount=approval.contract_amount,
    contract_party_a=approval.party_a,
    contract_party_b=approval.party_b,
    service_period=approval.service_period,
    service_deadline=approval.service_deadline,
    signing_date=None,  # 未签订
    project_status='not_started',
    contract_status='pending_review',  # 审批中
    settlement_status='unsettled',
    remark=f"来自审批：{approval.title}",
)
```

**关键点**:
- ✅ 审批通过后立即生成台账
- ✅ 合同状态标注为"待审核"（pending_review）
- ✅ 签订日期为空（未签订）
- ✅ 关联审批记录和台账记录

## 🎨 状态管理

### **审批状态**

| 状态 | 显示 | 颜色 | 说明 |
|------|------|------|------|
| `draft` | 草稿 | 灰色 | 未提交的草稿 |
| `pending` | 待审核 | 黄色 | 已提交，等待审批 |
| `reviewing` | 审核中 | 青色 | 正在审核中 |
| `approved` | 已通过 | 绿色 | 审批通过 |
| `rejected` | 已退回 | 红色 | 被退回，需要修改 |
| `cancelled` | 已撤销 | 灰色 | 申请人撤销 |

---

### **合同台账状态**

**审批中的合同**:
- `contract_status = 'pending_review'` → 待审核
- `signing_date = None` → 未签订
- 在合同台账列表中可识别为"审批中"

## 🚀 使用指南

### **1. 访问审批列表**

从侧边栏菜单：**合同管理 → 审批流程**

或直接访问：http://localhost:8000/contract-approval/

---

### **2. 新增审批**

1. 点击"新增审批"按钮
2. 填写表单：
   - 审批标题（必填）
   - 合同名称（必填）
   - 合同类别（工程监理、造价咨询等）
   - 合同金额
   - 申请部门
   - 合同甲方、乙方
   - 服务周期、到期时间
   - 备注
3. 上传附件（可多个）
4. 点击"立即提交"

---

### **3. 编辑审批**

只有**草稿**或**已退回**状态可以编辑：
1. 在列表页点击"编辑"按钮
2. 修改表单内容
3. 保存修改

---

### **4. 提交审批**

从草稿或已退回状态：
1. 进入审批详情页
2. 点击"提交审批"按钮
3. 状态变为"待审核"

---

### **5. 审批操作**

**管理员权限**：
1. 进入待审核的审批详情
2. 点击"审批操作"下拉菜单
3. 选择：
   - **同意**：审批通过，自动生成合同台账
   - **退回**：填写退回原因，审批被退回

---

### **6. 查看合同台账**

审批通过的合同会自动出现在：
- **合同管理 → 合同台账**
- 合同状态显示为"待审核"
- 可在台账中找到对应的审批来源
