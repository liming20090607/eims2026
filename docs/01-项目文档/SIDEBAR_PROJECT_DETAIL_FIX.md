## 💡 设计理念

### **为什么这样设计？**

1. **统一的入口** - 所有项目都通过"项目台账"访问
2. **一致的体验** - 所有项目的详情页结构相同
3. **清晰的层次** - 侧边栏 → 列表页 → 详情页
4. **易于维护** - 只需维护一个详情页模板

---

### **详情页的优势**

相比旧的详情页，新的项目台账详情页有以下优势：

| 特性 | 旧详情页 | 新详情页（项目台账） |
|------|---------|-------------------|
| **信息展示** | 简略 | 完整（6 个卡片） |
| **子窗体** | ❌ 无 | ✅ 3 个（动态、回款、人员） |
| **布局** | 简单列表 | 卡片式 + 表格 |
| **操作** | 基础 CRUD | 丰富的子记录管理 |
| **视觉** | 平淡 | 层次分明 |
