## 💡 使用场景

### **场景 1：首次导入**

**用户**: 我有一个新的 Excel 文件要导入

**操作流程**:
1. 访问导入页面
2. 看到"导入前建议"提示框
3. 点击"使用调试工具检查"按钮
4. 上传 Excel 文件进行预检查
5. 根据报告修正字段问题
6. 返回导入页面正式导入

**好处**: 避免导入失败，节省时间

### **场景 2：导入失败后**

**用户**: 刚才导入失败了，不知道哪里有问题

**操作流程**:
1. 导入页面显示错误信息
2. 看到提示框中的调试工具按钮
3. 点击按钮打开调试工具
4. 上传同一个 Excel 文件
5. 查看详细的问题分析
6. 修正问题后重新导入

**好处**: 快速定位问题，精准修复

### **场景 3：批量导入前验证**

**用户**: 我有多个 Excel 文件要导入，想先检查一下格式

**操作流程**:
1. 先用调试工具检查第一个文件
2. 确认格式正确
3. 批量导入所有类似格式的文件

**好处**: 确保批量导入的成功率

   - 文件：`eims_app/templates/contract_management/import.html`

### **HTML 结构**

```html
<div class="alert alert-warning">
    <i class="bi bi-exclamation-triangle me-2"></i>
    <strong>导入前建议：</strong>
    
    <!-- 调试工具按钮 -->
    <a href="/debug_import/" 
       target="_blank" 
       class="btn btn-sm btn-warning ms-2">
        <i class="bi bi-bug me-1"></i>使用调试工具检查
    </a>
    
    <!-- 快速帮助按钮 -->
    <a href="/static/import_quick_help.html" 
       target="_blank" 
       class="btn btn-sm btn-info ms-2">
        <i class="bi bi-question-circle me-1"></i>查看快速帮助
    </a>
</div>
```

### **CSS 类说明**

- `alert alert-warning`: 黄色警告提示框
- `btn btn-sm`: 小尺寸按钮
- `btn-warning`: 黄色警告按钮
- `btn-info`: 蓝色信息按钮
- `ms-2`: 左边距（margin-start）
- `me-1`: 右边距（margin-end）- 用于图标
- `target="_blank"`: 新标签页打开
