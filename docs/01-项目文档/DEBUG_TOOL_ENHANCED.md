# 🔍 调试工具增强版 - 详细字段匹配分析

## ✨ 新功能特性

我已经将调试工具升级为**增强版**，现在可以提供更详细的字段匹配分析！

### **新增功能**

1. **✅ 详细的字段匹配信息**
   - 显示每个字段映射到哪个数据库字段
   - 区分项目台账和合同管理的匹配情况

2. **✅ 智能相似性建议**
   - 为未匹配字段查找相似的正确字段名
   - 例如："开工日期" → 建议改为 "计划开工日期"

3. **✅ 完整的字段对照表**
   - 显示所有有效的字段名称
   - 按长度排序，方便查找

4. **✅ 数据库字段说明**
   - 列出数据库中实际存在的所有字段
   - 帮助你了解数据结构

5. **✅ 智能诊断建议**
   - 针对每个未匹配字段提供修正建议
   - 给出明确的修改步骤

## 🎯 如何使用

### **访问地址**
http://localhost:8000/debug_import/

### **使用步骤**

1. **上传 Excel 文件**
   - 点击"选择文件"
   - 选择你的 .xlsx 文件
   - 点击"🔍 开始详细分析"

2. **查看详细分析报告**
   
   报告包含以下内容：
   
   #### 📊 **Excel 文件信息**
   - 文件名、工作表名称
   - 数据行数、列数
   
   #### 📋 **表头字段匹配详情**
   
   | 序号 | Excel 表头 | 匹配结果 | 数据库字段 | 详细说明 |
   |------|----------|---------|-----------|---------|
   | 1 | 项目编号 | ✅ 项目台账 | `project_code` | 映射到数据库字段 |
   | 2 | 错误的字段 | ❌ 未匹配 | - | ⚠️ 可能是：正确的字段名 |
   
   #### 📈 **匹配统计**
   ```
   共 36 个表头
   ✅ 匹配成功 34 个
   ❌ 未匹配 2 个
   💡 有相似建议 2 个
   ```
   
   #### ⚠️ **未匹配字段详细分析**
   
   系统会显示：
   - 未匹配的字段列表
   - 最接近的正确字段名建议
   - 完整的字段名称对照表
   
   #### 💡 **智能建议**
   
   **如果全部匹配成功：**
   ```
   ✅ 完美！所有字段都已正确匹配
   您的 Excel 文件格式完全正确，可以直接导入。
   ```
   
   **如果有未匹配字段：**
   ```
   ⚠️ 需要修正以下问题：
   1. 将 "开工日期" 改为 "计划开工日期"
   2. 将 "完工时间" 改为 "预计竣工时间"
   
   📝 修正步骤：
   1. 打开 Excel 文件
   2. 根据上述建议修改表头名称
   3. 保存文件（.xlsx 格式）
   4. 重新上传进行验证
   ```

## 🎯 常见未匹配字段及解决方案

### **类型 1：同义词混淆**

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 开工日期 | 计划开工日期 | 缺少"计划" |
| 完工时间 | 预计竣工时间 | 用词不准确 |
| 负责人 | 现场负责人 | 缺少"现场" |
| 电话 | 联系电话 | 缺少"联系" |

### **类型 2：括号格式错误**

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 合同总价 (元) | 合同总价（元） | 英文括号 vs 中文括号 |
| 项目总投资 (万元) | 项目总投资（万元） | 英文括号 vs 中文括号 |

### **类型 3：多余或缺少空格**

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 项目 名称 | 项目名称 | 多余空格 |
| 合同甲方 | 合同甲 方 | 错误断字 |

### **类型 4：字段不存在**

| 错误字段 | 处理方式 | 说明 |
|---------|---------|------|
| 客户名称 | 删除此列 | 系统中没有这个字段 |
| 备注说明 | 改为"备注" | 字段名重复或错误 |

## 🔧 技术实现

### **智能匹配算法**

1. **精确匹配**
   - 完全相同的字段名
   - 包括标点符号和空格

2. **相似性检测**
   ```python
   # 检查是否包含相同的关键词
   if any(part in header_str for part in correct_name.split()):
       添加为相似建议
   ```

3. **多对一映射**
   - 支持多个别名映射到同一个字段
   - 例如："合同总价" 和 "合同总价（元）" 都映射到 `contract_amount`

### **数据库字段验证**

系统会自动：
- 从 Django ORM 获取实际的数据库字段
- 验证映射关系是否正确
- 确保不会导入不存在的字段
