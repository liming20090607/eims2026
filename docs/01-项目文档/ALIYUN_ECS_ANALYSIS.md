## 💡 优化建议（让 2 核 4GB 发挥最大性能）

### 1. 软件优化

#### **Gunicorn 配置优化**
```bash
# 2 核 CPU，建议配置
gunicorn wsgi:application \
    --bind 127.0.0.1:8000 \
    --workers 2 \          # CPU 核心数
    --threads 2 \          # 每个 worker 2 线程
    --worker-class gthread \
    --timeout 30 \
    --keep-alive 5
```

#### **Django 配置优化**
```python
# settings.py

# 关闭调试模式
DEBUG = False

# 启用缓存
CACHES = {
    'default': {
        'BACKEND': 'django.core.cache.backends.locmem.LocMemCache',
    }
}

# 数据库连接优化
DATABASES = {
    'default': {
        # ...
        'CONN_MAX_AGE': 60,  # 连接复用
        'ATOMIC_REQUESTS': True,
    }
}

# 静态文件压缩
STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'
```

---

### 2. 数据库优化

#### **MySQL 配置优化**
```ini
# /etc/mysql/my.cnf

[mysqld]
# 2 核 4GB 优化配置
innodb_buffer_pool_size = 1G      # 内存的 25%
max_connections = 100             # 限制连接数
query_cache_size = 32M
tmp_table_size = 64M
max_heap_table_size = 64M
```

#### **索引优化**
```sql
-- 为常用查询字段添加索引
ALTER TABLE personnel_personnel ADD INDEX idx_department (department);
ALTER TABLE personnel_personnel ADD INDEX idx_project (project_code);
ALTER TABLE contract_contract ADD INDEX idx_status (status);
```

---

### 3. 带宽优化

#### **启用 Gzip 压缩**
```nginx
# Nginx 配置
gzip on;
gzip_vary on;
gzip_min_length 1024;
gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
```

#### **静态资源使用 CDN**
```html
<!-- 将静态资源指向 CDN -->
<link rel="stylesheet" href="https://cdn.yourdomain.com/static/css/style.css">
```

---

### 4. 内存优化

#### **Swap 分区（防止 OOM）**
```bash
# 创建 2GB Swap
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 永久生效
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

**作用**：当物理内存不足时，使用磁盘空间作为虚拟内存
