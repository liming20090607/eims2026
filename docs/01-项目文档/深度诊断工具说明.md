## 🚨 常见错误类型

### **错误 1：数据重复**
```
❌ UNIQUE constraint failed: project_code
解决：修改为唯一的编号
```

### **错误 2：缺少必填字段**
```
❌ NOT NULL constraint failed: project_name
解决：填写项目名称
```

### **错误 3：选择字段无效**
```
❌ Value '建设中' is not a valid choice
解决：改为 '在施工'
```

### **错误 4：日期格式错误**
```
❌ 日期字段格式不正确：2026/1/15
解决：改为 2026-01-15
```

### **错误 5：金额格式错误**
```
❌ 金额不是有效数字：¥1,000,000
解决：改为 1000000.00
```

## 💡 使用流程

```
上传 Excel → 查看报告 → 修复错误 → 重新上传 → 导入成功
```

### **详细步骤**

1. **访问** http://localhost:8000/debug_import/
2. **上传** Excel 文件
3. **查看** "数据质量验证"部分
4. **修复** 所有严重错误
5. **查看** "模拟导入测试"结果
6. **如果通过** → 正式导入
7. **如果失败** → 根据错误提示修正

## 📋 必填字段清单

以下 5 个字段**必须填写**：

| 中文字段 | 英文字段 | 说明 |
|---------|---------|------|
| 项目编号 | project_code | 唯一标识 |
| 合同编号 | contract_code | 合同编号 |
| 项目名称 | project_name | 项目全称 |
| 合同甲方 | contract_party_a | 甲方单位 |
| 合同乙方 | contract_party_b | 乙方单位 |
