## 📊 核心功能

### 支持的场景

#### ✅ 一人多项目（跨项目兼职）
```
员工 A → 项目 X（工程部，技术员）
     → 项目 Y（技术部，技术负责人）
     → 项目 Z（质检部，质检员）
```

#### ✅ 同一项目部门唯一性
```
员工 A 在项目 X 只能有一个有效分配记录
❌ 不能同时在项目 X 的工程部和技术部
```

#### ✅ 完整的分配历史
```
每次分配都创建 PersonnelAllocation 记录
- 从哪个项目来
- 到哪个项目去
- 部门和岗位是什么
- 分配日期和状态
```

## 🔧 技术实现

### 数据表结构

**Personnel（项目人员）**
```python
project = ForeignKey('Project', verbose_name='主要项目')  # 可选
personnel_code = CharField()  # 人员编号
name = CharField()  # 姓名
department = CharField()  # 部门
position = CharField()  # 岗位
```

**PersonnelAllocation（人员分配记录）**
```python
personnel = ForeignKey('Personnel')  # 人员
to_project = ForeignKey('Project')   # 分配到的项目
from_project = ForeignKey('Project') # 原项目
allocation_department = CharField()  # 分配部门 ⭐新增
allocation_position = CharField()    # 分配岗位
allocation_date = DateField()        # 分配日期
allocation_status = CharField()      # 状态
```

### 验证逻辑

```python
# 检查是否已分配到该项目
existing = PersonnelAllocation.objects.filter(
    personnel=personnel,
    to_project=project,
    allocation_status='allocated'
).first()

if existing:
    skipped_count += 1  # 已分配，跳过
else:
    # 创建新分配记录
    PersonnelAllocation.objects.create(...)
    allocated_count += 1
```

### AJAX 接口增强

**请求：**
```javascript
POST /personnel/allocation/ajax/
```

## 📱 使用方法

### 可视化分配操作

1. **进入页面**
   - 侧边栏 → 人员管理 → 右上角"可视化分配"按钮

2. **选择人员**
   - 勾选要分配的人员（支持多选）

3. **点击"分配到项目"**
   - 弹出模态框

4. **填写信息**
   ```
   选择项目：[下拉选择] ⭐必填
   分配部门：[文本输入] 可选
   分配岗位：[文本输入] 可选
   分配日期：[日期选择] 默认今天
   ```

5. **提交**
   - 系统自动处理
   - 显示分配结果

## 🔍 查询示例

### 查询某人参与的所有项目
```python
from eims_app.models import PersonnelAllocation

personnel = Personnel.objects.get(pk=1)
allocations = PersonnelAllocation.objects.filter(
    personnel=personnel,
    allocation_status='allocated'
)

for alloc in allocations:
    print(f"项目：{alloc.to_project}")
    print(f"部门：{alloc.allocation_department}")
    print(f"岗位：{alloc.allocation_position}")
```

### 查询某项目的所有人员
```python
project_allocations = PersonnelAllocation.objects.filter(
    to_project__project_code='PRJ2026001',
    allocation_status='allocated'
)

for alloc in project_allocations:
    print(f"人员：{alloc.personnel.name}")
    print(f"部门：{alloc.allocation_department}")
```

### 查询某人的主要项目
```python
personnel = Personnel.objects.get(pk=1)
main_project = personnel.project  # 可能为 None
print(f"主要项目：{main_project}")
```
