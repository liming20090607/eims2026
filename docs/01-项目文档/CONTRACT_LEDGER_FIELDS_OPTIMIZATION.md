## 💡 技术实现

### **CSS 样式增强**

```css
/* 表格容器 */
.table-responsive {
    position: relative;
    max-height: calc(100vh - 350px);  /* 最大高度 */
    overflow: auto;  /* 超出滚动 */
}

/* 表头样式 */
.table thead th {
    font-size: 13px;
    font-weight: 600;
    white-space: nowrap;
    background-color: #f8f9fa;
    padding: 12px 8px;
    vertical-align: middle;
}

/* 单元格样式 */
.table tbody td {
    font-size: 13px;
    vertical-align: middle;
    padding: 12px 8px;
    white-space: nowrap;  /* 不换行 */
}

/* 悬停效果 */
.table tbody tr:hover {
    background-color: rgba(0, 123, 255, 0.05);
}

/* 固定列 */
.sticky-col {
    position: sticky;
    right: 0;
    background: inherit;
    z-index: 3;
    box-shadow: -2px 0 5px rgba(0,0,0,0.1);
}
```
