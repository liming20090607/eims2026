## 🚀 立即执行的步骤（按顺序）

### Step 1: 在本地打包项目（2 分钟）

#### 方式 A: 使用 Git（推荐）

**在 Windows PowerShell 执行**:

```powershell
# 1. 进入项目目录
cd E:\EIMS2026

# 2. 初始化 Git（如果还没有）
git init

# 3. 创建 .gitignore（已有，检查是否包含以下）
# .env
# __pycache__/
# *.pyc
# db.sqlite3
# media/
# staticfiles/
# venv/

# 4. 添加所有文件
git add .

# 5. 提交代码
git commit -m "准备部署到阿里云"

# 6. 创建 GitHub/Gitee 仓库并推送
# 访问 https://github.com 或 https://gitee.com 创建新仓库
# 然后执行：
git remote add origin https://github.com/你的用户名/eims.git
git branch -M main
git push -u origin main
```

**记录 Git 仓库地址**：`https://github.com/你的用户名/eims.git`

---

#### 方式 B: 压缩上传（简单）

**在 Windows 资源管理器执行**:

1. 选中 `E:\EIMS2026` 文件夹所有内容
2. 右键 → 发送到 → 压缩 (zipped) 文件夹
3. 重命名为 `EIMS2026.zip`

**上传到阿里云**（选择一种）:

**选项 1: 使用 SCP 命令**（PowerShell）:
```powershell
scp E:\EIMS2026.zip root@你的服务器 IP:/tmp/
```

**选项 2: 使用 SFTP 工具**（推荐新手）:
- 下载 FileZilla: https://filezilla-project.org/
- 连接信息:
  - 主机：你的服务器 IP
  - 用户名：root
  - 密码：服务器密码
  - 端口：22
- 上传 `EIMS2026.zip` 到 `/home/` 目录

---

### Step 2: 登录阿里云服务器（1 分钟）

**在 Windows PowerShell 执行**:

```powershell
# SSH 登录服务器
ssh root@你的服务器 IP
# 输入服务器密码
```

**或使用 PuTTY**:
- 下载地址：https://www.putty.org/
- Host Name: 你的服务器 IP
- Port: 22
- Connection type: SSH
- 点击 Open，输入用户名 root 和密码

## 🆘 遇到问题怎么办？

### 问题 1: 无法访问网站

**检查步骤**:
```bash
# 1. 检查服务状态
systemctl status eims
systemctl status nginx

# 2. 查看错误日志
tail -f /var/log/nginx/error.log

# 3. 重启所有服务
systemctl restart eims
systemctl restart nginx
```

**常见原因**:
- ❌ 安全组未开放 80 端口
- ❌ Nginx 未启动
- ❌ Gunicorn 未启动

---

### 问题 2: 502 Bad Gateway

**解决**:
```bash
# Gunicorn 未运行
systemctl start eims

# 检查 socket 文件
ls -la /home/eims/eims.sock
```

---

### 问题 3: 数据库连接失败

**检查**:
```bash
# 测试数据库连接
mysql -u eims_user -p

# 查看 .env 配置
cat .env

# 检查 MySQL 服务
systemctl status mysql
```

---

### 问题 4: 静态文件 404

**解决**:
```bash
cd /home/eims
source venv/bin/activate
python manage.py collectstatic --noinput
systemctl restart eims
```
