### 技巧 3：合理选择配置

#### **可以省钱的配置**

```
✅ 数据库自建（省 ¥200/月）
   自己安装 MySQL，不用 RDS
   风险：需要自己维护、备份

✅ 不用 CDN（省 ¥15-20/月）
   小规模用户可以直接访问
   影响：访问速度稍慢

✅ 减少 OSS 容量（省 ¥5-10/月）
   先用免费额度，不够再加
   限制：只有 5GB 免费

✅ 手动备份（省 ¥6/月）
   写脚本定时备份到本地
   缺点：需要自己维护脚本
```

#### **不能省的配置**

```
❌ 带宽不能省
   没有带宽外网无法访问
   
❌ 域名不能省
   必须有自己的域名才能配 HTTPS
   
❌ SSL 证书不能省（但可以用免费版）
   必须用 HTTPS 保证安全
   
❌ 内存不能省
   4GB 是底线，再少会卡
```
