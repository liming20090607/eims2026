## 🚀 使用说明

### **导入数据步骤：**

1. **准备 Excel 文件**
   - 确保第一行是表头（字段名）
   - 从第二行开始是数据
   - 字段名与你的 Excel 完全一致

2. **访问导入页面**
   - 项目台账：`http://localhost:8000/project_ledger/import/`
   - 合同管理：`http://localhost:8000/contract_management/import/`

3. **上传文件**
   - 选择 Excel 文件
   - 系统会自动识别字段
   - 支持混合使用新旧字段名

4. **查看结果**
   - 成功：显示导入记录数
   - 失败：显示具体错误行和原因
