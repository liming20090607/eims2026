## 📋 基础操作教程

### ✅ 任务 1：将人员分配到部门

1. **选择人员**
   - 方法 A：勾选左侧列表中的人员复选框
   - 方法 B：双击人员所在行（快速选择）
   - 方法 C：点击表头"全选"复选框

2. **执行分配**
   - 点击 **"分配到部门"** 按钮
   - 选择目标部门（如：工程部）
   - 点击 **"确认分配"**

3. **查看结果**
   - 页面自动刷新
   - 人员的部门信息已更新

---

### ✅ 任务 2：将人员分配到项目

1. **选择待分配人员**
   - 在左侧"待分配人员"列表中勾选需要分配的人员
   - 可多选，支持跨部门选择

2. **打开项目分配对话框**
   - 点击 **"分配到项目"** 按钮
   - 系统弹出项目分配对话框

3. **填写分配信息**
   ```
   选择项目：XX 工程项目（必选）
   分配岗位：技术员（可选）
   分配日期：2026-03-21（默认今天）
   ```

4. **确认分配**
   - 点击 **"确认分配"** 按钮
   - 系统提示："成功分配 X 名人员到项目 XX 项目"

5. **验证结果**
   - 左侧列表：人员减少（已分配的人员消失）
   - 右侧列表：新增已分配人员
   - 项目详情页：项目人员数量增加
   - 人员花名册：人员项目信息更新

---

### ✅ 任务 3：从项目召回人员

#### 单个召回
1. 在右侧"已分配人员"列表中找到目标人员
2. 点击该行的 **"召回"** 按钮（红色）
3. 确认召回操作
4. 人员回到左侧"待分配人员"列表

#### 批量召回
1. 勾选右侧列表中需要召回的多个人员
2. 点击 **"批量召回"** 按钮
3. 确认批量召回
4. 所有选中人员回到待分配状态

## 💡 实用技巧

### 技巧 1：快速筛选人员
在搜索框输入：
- **姓名**：如 "张三"
- **编号**：如 "PER001"
- **部门**：如 "工程部"

快速定位目标人员！

### 技巧 2：双击快速选择
- 不需要精确点击复选框
- 双击人员行的任意位置即可选中
- 再次双击取消选择

### 技巧 3：先部门后项目
推荐的最佳实践：
1. 先将人员分配到部门（如：工程部）
2. 再将部门人员批量分配到项目
3. 便于组织管理和统计

### 技巧 4：查看分配历史
访问 **人员分配管理** 页面：
- URL: http://localhost:8000/personnel/allocations/
- 查看所有分配记录
- 支持按状态、项目筛选

## 🎯 常见使用场景

### 场景 A：新项目团队组建
```
背景：公司中标新项目，需要组建项目团队

操作步骤：
1. 进入可视化分配页面
2. 筛选合适人员（可按部门、技能等）
3. 批量选择 10-20 名人员
4. 点击"分配到项目"
5. 选择新项目，设置岗位
6. 确认分配

结果：
✅ 项目团队快速组建完成
✅ 所有人员项目信息已更新
✅ 项目详情页显示新团队名单
```

### 场景 B：项目完工人员调配
```
背景：A 项目完工，需要将人员调配到新开工的 B 项目

操作步骤：
1. 在右侧找到 A 项目的所有人员
2. 批量勾选（或用筛选功能）
3. 点击"批量召回"
4. 人员回到待分配状态
5. 重新选择这些人员
6. 点击"分配到项目"→B 项目

结果：
✅ 人员从 A 项目转移到 B 项目
✅ 分配记录完整保存
✅ 可追溯人员流动历史
```

## ❓ 常见问题解答

### Q1: 为什么我看不到"可视化分配"按钮？
**A**: 确保您已登录且具有超级用户权限。只有超级用户才能执行分配操作。

### Q2: 分配后人员花名册没有更新？
**A**: 请刷新页面（F5）。如果仍未更新，检查是否分配成功（看是否有成功提示）。

### Q3: 可以同时分配到多个项目吗？
**A**: 不支持。一个人员同一时间只能属于一个项目。如需调整，需先召回再分配。

### Q4: 如何修改已分配人员的岗位？
**A**: 有两种方式：
- 方式 1：召回该人员，重新分配时设置新岗位
- 方式 2：在人员花名册中编辑该人员记录

### Q5: 分配记录可以删除吗？
**A**: 可以。访问"人员分配管理"页面 (`/personnel/allocations/`) 进行删除操作。

## 🆘 遇到问题怎么办？

### 问题排查步骤：

4. **查看后端日志** - 终端是否有 Python 错误
5. **联系管理员** - 如问题持续存在
