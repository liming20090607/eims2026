### 三、核心功能

#### 1. 部门管理模块

**模型**: `Department`

**功能**:
- ✅ 部门信息管理（名称、编号、类型）
- ✅ 部门负责人设置
- ✅ 联系方式管理（电话、邮箱）
- ✅ 职能描述和职责说明
- ✅ 部门状态控制（正常/停用/合并中）
- ✅ 成立日期记录
- ✅ 排序管理
- ✅ 层级结构支持（上级部门）
- ✅ 自动统计部门人数

**字段详情**:
```python
department_code      # 唯一标识，如：DEPT001
department_name      # 部门名称，如：工程部
department_type      # functional/project/temporary
parent_department    # 上级部门（支持树形结构）
manager_name         # 负责人姓名
contact_phone/email  # 联系方式
description          # 部门简介
responsibilities     # 详细职能
status               # active/inactive/merging
established_date     # 成立日期
order                # 排序顺序
```

---

#### 2. 部门角色模块

**模型**: `DepartmentRole`

**功能**:
- ✅ 部门内角色配置
- ✅ 用户与角色绑定
- ✅ 角色类型管理（经理/副职/主管/成员/助理）
- ✅ 主要负责人标记
- ✅ 权限列表配置

**角色类型**:
```python
manager     # 部门经理 - 全面负责
deputy      # 部门副职 - 协助经理
supervisor  # 主管 - 分管特定领域
member      # 普通成员 - 执行工作
assistant   # 助理 - 辅助支持
```

**约束**:
- 同一部门、同一用户、同一角色类型只能有一个配置
- 可通过 `is_primary` 标记主要负责人

---

#### 3. 审批链模块

**模型**: `ApprovalChain`

**功能**:
- ✅ 多级审批配置（最多三级）
- ✅ 审批类型选择（逐级/并行/混合）
- ✅ 业务类型分类
- ✅ 跨部门协同支持
- ✅ 审批链启用/禁用

**业务类型**:
```python
personnel_allocate  # 人员分配
personnel_transfer  # 人员调动
leave_apply         # 请假申请
expense_apply       # 费用报销
contract_sign       # 合同签订
payment_apply       # 付款申请
other              # 其他
```

**审批类型**:
```python
sequential  # 逐级审批 - 按顺序一级一级审批
parallel    # 并行审批 - 多个审批人同时审批
hybrid      # 混合审批 - 部分逐级，部分并行
```

### 当前状态

在 `allocation_visual.html` 中，部门选择是硬编码的：

```html
<select name="department" id="departmentSelect">
    <option value="">请选择部门</option>
    <option value="工程部">工程部</option>
    <option value="技术部">技术部</option>
    ...
</select>
```

### 优化方案

修改为动态加载：

```html
<select name="department" id="departmentSelect">
    <option value="">请选择部门</option>
    {% for dept in all_departments %}
    <option value="{{ dept.department_name }}">
        {{ dept.full_path }}
    </option>
    {% endfor %}
</select>
```

并在视图中传入部门数据：

```python
# views_allocation_visual.py
def allocation_visual(request):
    
    context['all_departments'] = Department.objects.filter(
        status='active',
        is_deleted=False
    ).order_by('order')
    
    return render(request, "personnel/allocation_visual.html", context)
```
