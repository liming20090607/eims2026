# EIMS 审批流程系统使用说明

## 一、系统概述

本系统实现了项目月度报告的多级审批流程，支持权限控制和实时状态追踪。

## 二、角色说明

### 1. 系统角色
- **超级管理员**（admin）：拥有所有权限，可进行最终审批
- **系统管理员**：协助超级管理员管理

### 2. 项目角色
每个项目配备以下人员：
- **项目总监**（张三）：负责项目最终审核
- **总监代表**（李四）：协助总监工作
- **监理员**（王五、赵六等）：现场监理，可发起填报
- **资料员**（孙七）：负责资料管理，可发起填报

## 三、审批流程

```
发起人提交 → 项目总监审核 → 系统管理员审批 → 完成
```

### 流程状态：
1. **草稿**（draft）- 刚创建，未提交
2. **待总监审核**（pending_review）- 已提交，等待项目总监审核
3. **待管理员审批**（pending_approval）- 总监已通过，等待管理员审批
4. **已批准**（approved）- 审批通过
5. **已退回**（rejected）- 被退回，需要重新修改提交
6. **已取消**（cancelled）- 已取消

## 五、操作步骤

### 1. 发起填报（监理员/资料员）
1. 登录系统
2. 进入"月度报告"菜单
3. 点击"创建月度报告"
4. 填写报告内容
5. 保存为草稿或直接提交

### 2. 提交审核
1. 在月度报告列表中找到要提交的报告
2. 点击"提交"按钮
3. 确认提交
4. 状态变为"待总监审核"

### 3. 总监审核（张三）
1. 登录后进入"审批流程"或"我待审核的"
2. 查看待审核的报告详情
3. 点击"总监审核"
4. 填写审核意见
5. 选择"通过"或"退回"
   - 通过：状态变为"待管理员审批"
   - 退回：状态变为"已退回"，发起人需要重新修改

### 4. 管理员审批（admin）
1. 进入"审批流程管理"
2. 查看待审批的报告
3. 点击"管理员审批"
4. 填写审批意见
5. 选择"通过"或"退回"
   - 通过：状态变为"已批准"，流程结束
   - 退回：状态变为"已退回"，需要重新走流程

## 六、权限控制

### 访问权限
- 只有本项目人员可以查看和编辑本项目的报告
- 系统管理员可以查看所有项目
- 超级管理员拥有所有权限

### 操作权限
- **发起人**：创建、编辑草稿、提交
- **项目总监**：审核（通过/退回）
- **系统管理员**：最终审批（通过/退回）

## 七、功能菜单

1. **月度报告** - 创建和编辑月度报告
2. **月度填报仪表板** - 查看待填报提醒
3. **审批流程管理** - 查看所有审批流程
4. **我待审核的** - 查看需要自己处理的流程

## 八、注意事项

1. 每月 25 日前必须完成填报
2. 报告一旦被批准，将不能修改
3. 被退回的报告需要重新提交审核
4. 所有审核操作都会记录在案，包括操作人、时间和意见
5. 可以通过审批记录查看完整的流程历史

## 十、常见问题

**Q: 如何知道有待审核的报告？**
A: 登录后查看"我待审核的"菜单，会显示所有需要您处理的报告。

**Q: 退回后需要重新走流程吗？**
A: 是的，退回的报告需要发起人重新提交，从总监审核开始。

**Q: 可以同时担任多个角色吗？**
A: 可以，系统支持一个用户在不同项目中担任不同角色。

**Q: 如何查看审批进度？**
A: 在"审批流程管理"中点击"详情"，可以看到当前步骤和所有审批记录。
