## 📊 字段分配

### Employee（员工信息）- 入职登记
**基本信息：**
- employee_code（员工编号）
- name（姓名）
- gender（性别）
- id_card（身份证号）⭐
- native_place（籍贯）⭐
- ethnic（民族）⭐
- education（学历）⭐

**联系方式：**
- mobile（手机号）⭐
- home_phone（固定电话）⭐
- address（住址）⭐
- wechat（微信）⭐
- emergency_contact（应急联系人）⭐
- emergency_phone（应急电话）⭐

**职务信息：**
- admin_position（行政职务）⭐
- tech_position（技术职务）⭐
- professional_qualification（执业资格）⭐
- professional_title（职称）⭐
- job_qualification（任职资格）⭐

**时间信息：**
- entry_time（入职时间）
- leave_time（离职时间）

### Personnel（项目人员）- 二次分配
**基本信息：**
- personnel_code（人员编号）
- name（姓名）
- gender（性别）

**项目信息：**
- project_code（项目编号）⭐
- project（所在项目）⭐
- department（部门）⭐
- position（岗位）⭐

**联系方式：**
- phone（手机号码）
- email（邮箱）

**时间信息：**
- entry_time（入岗时间）
- leave_time（离岗时间）

**其他：**
- remark（备注）

## 🎯 核心优势

1. **职责分离**：人事管理 vs 项目管理
2. **数据复用**：员工信息只需录入一次
3. **灵活分配**：一个员工可参与多个项目
4. **历史追溯**：完整保留项目调动记录
5. **易于统计**：快速统计员工项目参与情况

## 🚀 如何使用

### 方式 1：通过侧边栏菜单
1. 登录系统（需要超级管理员权限）
2. 点击左侧菜单 **"员工信息"**
3. 进行员工的增删改查操作

### 方式 2：直接访问 URL
- 员工列表：http://127.0.0.1:8000/employee/
- 添加员工：http://127.0.0.1:8000/employee/add/

### 方式 3：Django Admin
1. 访问：http://127.0.0.1:8000/admin/
2. 找到 **"员工信息"** 模块
3. 进行数据管理
