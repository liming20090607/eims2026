## ⚠️ **重要提示**

### **1. 必填字段验证**
```
项目台账：
❌ 缺少必填字段 → 导入失败
✅ 所有必填字段完整 → 导入成功

合同管理：
❌ 缺少必填字段 → 导入失败
✅ 所有必填字段完整 → 导入成功
```

### **2. 数据格式**
```
日期格式：YYYY-MM-DD
示例：2024-01-15 ✅
错误：2024/01/15 ❌

数字格式：纯数字，不含千分位
示例：1000000 ✅
错误：1,000,000 ❌

布尔值：是/否
示例：是 ✅
示例：否 ✅
```

### **3. 重复数据处理**
```
项目台账：
- 按"项目编号"判断是否重复
- 如果项目编号已存在 → 自动更新该项目的数据
- 如果项目编号不存在 → 创建新项目

合同管理：
- 按"合同编号"判断是否重复
- 如果合同编号已存在 → 自动更新该合同的数据
- 如果合同编号不存在 → 创建新合同
```

### **4. 错误处理**
```
导入失败时：
- 显示失败行数
- 显示具体错误信息（前 5 条）
- 成功的记录仍会保存
- 失败的记录不影响其他记录
```

## 📞 **常见问题**

### **Q1: 导入后为什么看不到数据？**
**A**: 可能是以下原因：
1. 浏览器缓存 → 强制刷新（Ctrl + F5）
2. 导入失败 → 查看错误提示
3. 筛选条件 → 清除筛选条件

### **Q2: 为什么提示"缺少必填字段"？**
**A**: 检查 Excel 模板：
1. 确认必填字段列名完全正确
2. 确认必填字段都有值
3. 确认没有空格或特殊字符

### **Q3: 导入的数据为什么在另一个模块看不到？**
**A**: 理论上应该同步，检查：
1. 是否导入到正确的表（ProjectDetail）
2. 是否在正确的模块查看
3. 浏览器缓存问题

### **Q4: 如何处理大量数据导入？**
**A**: 建议分批导入：
1. 每批不超过 1000 条
2. 先测试小批量数据
3. 确认无误后再导入全部
