# 人员管理模块导航说明

## 📍 如何找到三个功能模块

### 方式一：侧边栏菜单（推荐）

1. **登录系统**后，查看左侧导航菜单
2. 找到 **"人员管理"** 菜单项（带有人形图标 👥）
3. 点击展开，可以看到 5 个子菜单：

```
人员管理 (3)
├── 📊 模块导航          ← 新手指引页面
├── 📋 人员花名册        ← 人员基本信息管理
├── 🏆 人员证书          ← 证书信息管理
└── 👤 人员分配          ← 项目/部门分配
    └── 🎯 可视化分配    ← 交互式批量操作
```

### 方式二：直接访问 URL

#### 1. 模块导航页面（推荐起点）
```
http://localhost:8000/personnel/navigation/
```
这个页面展示了所有三个功能模块的详细介绍和快速入口。

#### 2. 人员花名册
```
http://localhost:8000/personnel/
```
人员基本信息管理，包含详细的员工档案。

#### 3. 人员证书
```
http://localhost:8000/personnel/certificates/
```
证书信息管理，支持上传证书扫描件。

#### 4. 人员分配列表
```
http://localhost:8000/personnel/allocations/
```
查看和管理所有人员分配记录。

#### 5. 可视化分配（推荐）
```
http://localhost:8000/personnel/allocation-visual/
```
直观的交互式分配界面，支持批量操作。

## 🎯 三大核心功能模块

### 模块一：人员花名册 📋

**功能定位**：完整的人员信息数据库

**主要功能**：
- ✅ 人员基本信息管理（姓名、性别、身份证号等）
- ✅ 详细联系方式（手机、固话、微信、住址等）
- ✅ 职务职称信息（行政职务、技术职务、职称等）
- ✅ 入职离职管理
- ✅ Excel 导入导出
- ✅ 多条件筛选搜索

**关键字段**：
```
人员编号、姓名、性别、身份证号、籍贯、民族、学历
部门、住址、固定电话、手机号、应急联系人、应急电话、微信
行政职务、技术职务、执业资格、职称、任职资格
入职时间、离职时间
```

**访问路径**：
- 侧边栏 → 人员管理 → 人员花名册
- URL: `/personnel/`

---

### 模块二：人员证书 🏆

**功能定位**：专业证书全生命周期管理

**主要功能**：
- ✅ 证书信息管理（证书名称、类型、发证机关等）

- ✅ 证书附件上传（支持扫描件）
- ✅ 有效期管理

**证书类型**：
```
职业资格证书
培训证书
学历证书
专业技术证书
其他证书
```

**关键字段**：
```
证书编号、人员编号、证书名称、证书类型
发证机关、发证日期、有效期至
证书附件（扫描件）、备注
```

**访问路径**：
- 侧边栏 → 人员管理 → 人员证书
- URL: `/personnel/certificates/`

## 🔗 数据关联关系

### 核心理念
**所有模块通过"人员编号"进行关联**

```
人员花名册（基础数据中心）
    ↓
人员编号（唯一标识）
    ↓
人员证书、人员分配（扩展数据）
```

### 数据同步示例

#### 示例 1：分配到项目
```
操作步骤：
1. 进入"可视化分配"
2. 选择人员 → 分配到 XX 项目
3. 系统自动处理：

数据变化：
✅ Personnel 表：project 字段更新为新项目
✅ PersonnelAllocation 表：新增分配记录
✅ 花名册页面：显示最新项目信息
✅ 项目详情页：人员列表自动增加
```

#### 示例 2：添加证书
```
操作步骤：
1. 进入"人员证书"
2. 添加证书 → 选择人员
3. 系统自动处理：

数据变化：
✅ PersonnelCertificate 表：新增证书记录
✅ personnel_code 自动关联到花名册
✅ 可通过人员编号查询证书信息
```

#### 示例 3：修改部门
```
操作步骤：
1. 在花名册中修改某人的部门
2. 或在可视化分配中批量调整部门

数据变化：
✅ Personnel 表：department 字段更新
✅ 所有相关视图中的部门信息同步更新
```

## 🚀 快速上手指南

### 场景 A：录入新员工

```
步骤 1：进入人员花名册
   - 侧边栏 → 人员管理 → 人员花名册

步骤 2：添加人员
   - 点击"添加人员"按钮
   - 填写基本信息（必填：人员编号、姓名）
   - 补充详细信息（可选）
   - 保存

步骤 3：分配部门（可选）
   - 进入"可视化分配"
   - 选择该员工 → "分配到部门"
   - 选择部门 → 确认

步骤 4：分配项目（可选）
   - 在"可视化分配"中
   - 选择该员工 → "分配到项目"
   - 选择项目和岗位 → 确认
```

### 场景 B：为老员工添加证书

```
步骤 1：进入人员证书
   - 侧边栏 → 人员管理 → 人员证书

步骤 2：添加证书
   - 点击"添加证书"按钮
   - 选择人员（或通过人员编号）
   - 填写证书信息
   - 上传证书扫描件（可选）
   - 保存

步骤 3：查看证书
   - 在证书列表中查找
   - 或从花名册中找到该人员
   - 点击查看其证书信息
```

### 场景 C：批量调配人员

```
步骤 1：进入可视化分配
   - 侧边栏 → 人员管理 → 可视化分配

步骤 2：选择人员
   - 勾选需要调配的多名员工
   - 或双击快速选择

步骤 3：批量分配
   - 点击"分配到项目"
   - 选择目标项目
   - 设置岗位和日期
   - 确认分配

结果：
✅ 所有选中人员一次性分配到项目
✅ 花名册自动更新
✅ 项目人员列表自动同步
✅ 创建完整的分配历史记录
```

## ❓ 常见问题

### Q1: 为什么看不到这些模块？
**A**: 请确保：
1. 已登录系统
2. 具有相应权限（至少是普通用户）
3. 刷新页面（Ctrl+F5 清除缓存）

### Q2: 侧边栏没有展开怎么办？
**A**: 
- 点击"人员管理"文字或图标即可展开
- 如果无法展开，刷新页面重试

### Q3: 三个模块的数据真的同步吗？
**A**: 
- 是的！所有模块通过人员编号关联
- 分配操作会自动更新花名册
- 添加证书会自动关联到人员

### Q4: 如何查看所有功能？
**A**: 
- 访问模块导航页面：`/personnel/navigation/`
- 该页面展示了所有功能和快速入口
