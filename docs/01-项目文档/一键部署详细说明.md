# 🚀 一键部署使用说明

## ⚡ 快速开始（3 分钟完成）

### 前提条件
✅ 阿里云服务器（Ubuntu/CentOS）  
✅ MySQL 已安装并运行  
✅ Python 3.8+ 已安装  
✅ 项目代码已上传到服务器  

---

## 📋 部署步骤

### Step 1: 上传代码到服务器

**选择一种方式**:

#### 方式 A: Git 克隆（推荐）
```bash
# 在服务器上执行
cd /home
git clone <你的仓库地址> eims
cd eims
```

#### 方式 B: SFTP 上传
使用 FileZilla 或 WinSCP 上传整个项目到 `/home/eims/`

---

### Step 2: 执行一键部署脚本

```bash
# 进入项目目录
cd /home/eims

# 赋予脚本执行权限
chmod +x deploy.sh

# 执行部署
bash deploy.sh
```

---

### Step 3: 跟随提示操作

脚本会自动询问以下配置：

1. **数据库密码** - 直接回车使用随机密码，或输入自定义密码
2. **项目目录** - 默认当前目录，直接回车
3. **SECRET_KEY** - 直接回车使用随机密钥，或输入自定义密钥
4. **管理员账号** - 按提示输入用户名、邮箱、密码

## 🆘 故障排查

### 问题 1: 无法访问网站

**检查步骤**:
```bash
# 1. 检查服务状态
systemctl status eims
systemctl status nginx

# 2. 查看错误日志
tail -f /var/log/nginx/error.log

# 3. 重启所有服务
systemctl restart eims
systemctl restart nginx
```

**常见原因**:
- Nginx 未启动
- Gunicorn 未启动
- 防火墙阻止 80 端口
- 阿里云安全组未开放 80 端口

---

### 问题 2: 502 Bad Gateway

**原因**: Gunicorn 未运行或 socket 文件不存在

**解决**:
```bash
# 检查 Gunicorn 状态
systemctl status eims

# 如果未运行，启动它
systemctl start eims

# 查看 Gunicorn 日志
journalctl -u eims -f

# 检查 socket 文件
ls -la /home/eims/eims.sock
```

---

### 问题 3: 数据库连接失败

**检查**:
```bash
# 测试数据库连接
mysql -u eims_user -p

# 查看 .env 配置
cat .env

# 检查 MySQL 服务
systemctl status mysql
```

**解决**:
```bash
# 重启 MySQL
systemctl restart mysql

# 重新配置 .env 文件
nano .env
```

---

### 问题 4: 静态文件 404

**解决**:
```bash
cd /home/eims
source venv/bin/activate

# 重新收集静态文件
python manage.py collectstatic --noinput

# 重启服务
systemctl restart eims
```

## 📊 部署架构说明

```
用户访问
   ↓
Nginx (端口 80)
   ↓
Gunicorn (Unix Socket)
   ↓
Django 应用
   ↓
MySQL 数据库
```

**组件说明**:
- **Nginx**: 反向代理服务器，处理静态文件和请求转发
- **Gunicorn**: WSGI 服务器，运行 Django 应用
- **Django**: EIMS 应用本身
- **MySQL**: 数据存储

## 💡 最佳实践

### 1. 定期备份
```bash
# 添加到 crontab
crontab -e

# 每天凌晨 2 点备份数据库
0 2 * * * /home/eims/backup_db.sh

# 每周日凌晨 3 点备份整个项目（可选）
0 3 * * 0 tar -czf /backups/eims_$(date +\%Y\%m\%d).tar.gz /home/eims
```

---

### 2. 监控日志
```bash
# 实时监控错误日志
tail -f /var/log/nginx/error.log

# 查看最近的错误
tail -100 /var/log/nginx/error.log | grep ERROR
```

---

### 3. 性能优化
```bash
# 调整 Gunicorn worker 数量（根据 CPU 核心数）
# 编辑 /etc/systemd/system/eims.service
--workers 3  # 改为：--workers $((2 * $(nproc) + 1))

# 重载配置
systemctl daemon-reload
systemctl restart eims
```

---

### 4. 安全加固
```bash
# 修改 .env 中的密码
nano .env

# 限制数据库用户权限
mysql -u root -p
> REVOKE ALL ON *.* FROM 'eims_user'@'localhost';
> GRANT SELECT, INSERT, UPDATE, DELETE ON eims_db.* TO 'eims_user'@'localhost';
> FLUSH PRIVILEGES;
```

## 🔐 安全建议

### 必须完成的安全措施

1. **修改默认密码**
   - 数据库密码
   - Django SECRET_KEY
   - 管理员密码

2. **配置防火墙**
   ```bash
   # Ubuntu
   ufw allow 22/tcp
   ufw allow 80/tcp
   ufw enable
   
   # CentOS
   firewall-cmd --permanent --add-port=22/tcp
   firewall-cmd --permanent --add-port=80/tcp
   firewall-cmd --reload
   ```

3. **定期更新系统**
   ```bash
   apt update && apt upgrade -y  # Ubuntu
   yum update -y                 # CentOS
   ```

4. **配置 HTTPS**（强烈推荐）
   ```bash
   # 安装 certbot
   apt install certbot python3-certbot-nginx -y
   
   # 获取证书
   certbot --nginx
   
   # 自动续期
   certbot renew --dry-run
   ```
