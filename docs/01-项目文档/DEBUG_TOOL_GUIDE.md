## 📋 使用步骤

### **步骤 1：确保服务器运行**
打开浏览器访问：http://localhost:8000/
- 如果能正常访问，说明服务器已在运行
- 如果无法访问，请先启动服务器（见上方）

### **步骤 2：访问调试工具**
在浏览器中输入：**http://localhost:8000/debug_import/**

### **步骤 3：上传 Excel 文件**
1. 点击"选择文件"按钮
2. 选择你的 Excel 文件（.xlsx 格式）
3. 点击"上传并调试"按钮

### **步骤 4：查看调试结果**
系统会显示详细的分析报告，包括：

#### ✅ **Excel 文件信息**
- 文件名、文件大小
- 工作表数量及名称
- 数据行数和列数

#### ✅ **表头字段分析**
- ✓ 已匹配的字段（绿色）
- ✗ 未匹配的字段（红色）
- 每个字段对应的数据库字段名

#### ✅ **数据预览**
- 前 5 行数据的详细展示
- 数据类型验证
- 潜在问题提示

#### ✅ **数据库字段验证**
- 模型包含的所有字段
- 字段类型说明
- 必填字段标注

#### ✅ **智能建议**
- 针对发现的问题提供解决方案
- 字段映射修正建议
- 格式调整建议

## 🎯 常见用途

### **用途 1：诊断导入失败**
当导入 Excel 文件提示"格式有误"时：
1. 上传文件到调试工具
2. 查看哪些字段未匹配
3. 根据建议修改 Excel 文件

### **用途 2：验证字段映射**
创建新的 Excel 模板后：
1. 上传到调试工具验证
2. 确认所有字段都正确映射
3. 再进行实际导入

### **用途 3：学习数据结构**
不了解数据库结构时：
1. 访问调试工具
2. 查看数据库字段说明
3. 了解每个字段的类型和要求

## ⚠️ 注意事项

### **1. 开发环境专用**
- 调试工具仅供开发测试使用
- 生产环境应禁用此功能
- 不要在生产服务器上启用

### **2. 文件格式要求**
- 仅支持 `.xlsx` 格式
- 第一行必须是表头（中文列名）
- 从第二行开始是数据
- 不要有合并单元格

### **3. 登录要求**
- 需要先登录系统才能访问
- 如果没有登录，会重定向到登录页

### **4. 数据安全**
- 上传的文件仅在当前会话中处理
- 不会保存到服务器
- 关闭浏览器后自动清除

## 🆘 故障排除

### **问题 1：无法访问调试工具页面**
**症状**: 访问 http://localhost:8000/debug_import/ 显示 404 或无法连接

**解决方案**:
1. 检查服务器是否运行：访问 http://localhost:8000/
2. 如果服务器未运行，执行：`python manage.py runserver`
3. 检查 URL 是否正确输入

### **问题 2：页面提示需要登录**
**症状**: 访问调试工具时被重定向到登录页

**解决方案**:
1. 先登录系统（使用你的用户名和密码）
2. 登录后再访问调试工具

### **问题 3：上传文件后没有反应**
**症状**: 上传文件后页面不响应

**解决方案**:
1. 检查文件大小是否合理（通常 < 10MB）
2. 确认是 `.xlsx` 格式（不是 `.xls`）
3. 查看浏览器控制台是否有错误信息

### **问题 4：显示乱码**
**症状**: 中文字段显示为乱码

**解决方案**:
1. 确保 Excel 文件保存为 UTF-8 编码
2. 使用 Microsoft Excel 而非 WPS 编辑
3. 重新保存文件后再上传

## 💡 使用技巧

### **技巧 1：对比工具**
可以同时打开多个浏览器标签：
- 标签 1：调试工具
- 标签 2：原始 Excel 文件
- 标签 3：导入页面

方便对比和修改。

对于大型 Excel 文件：
1. 先复制前 5 行创建测试文件
2. 在调试工具中验证
3. 确认无误后再导入完整文件

调试结果页面可以：
1. 截图保存错误信息
2. 复制粘贴到文本编辑器
3. 作为修改 Excel 的参考
