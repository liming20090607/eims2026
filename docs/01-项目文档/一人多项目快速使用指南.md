# 一人多项目功能 - 快速使用指南

## 🎯 核心功能

**同一个人可以分配到多个项目**，但在同一项目中只能有一个有效分配。

---

## 📱 操作演示

### 场景 1：将员工 A 分配到项目 X

1. **进入可视化分配页面**
   - 侧边栏 → 人员管理 → 右上角"可视化分配"按钮

2. **选择要分配的人员**
   - 在"未分配人员"列表中勾选员工 A
   - 可多选（支持批量分配）

3. **点击"分配到项目"按钮**

4. **填写分配信息**
   ```
   选择项目：[项目 X] ⭐必填
   分配部门：[工程部]  可选
   分配岗位：[技术员]  可选
   分配日期：[2026-03-21]  默认今天
   ```

5. **提交**
   - 点击"确定"
   - 系统提示："成功分配 1 名人员到项目 X"

---

### 场景 2：将同一个人员工 A 再分配到项目 Y（兼职）

1. **重复场景 1 的步骤**
   - 勾选员工 A（现在在"已分配人员"列表中）
   - 点击"分配到项目"

2. **选择项目 Y**
   ```
   选择项目：[项目 Y]
   分配部门：[技术部]
   分配岗位：[技术负责人]
   分配日期：[2026-03-22]
   ```

3. **提交成功**
   - 系统提示："成功分配 1 名人员到项目 Y"
   - ✅ 员工 A 现在同时参与项目 X 和项目 Y

---

### 场景 3：尝试再次将员工 A 分配到项目 X（重复）

1. **勾选员工 A，选择项目 X**

2. **提交后系统提示**
   ```
   成功分配 0 名人员到项目 X，跳过 1 名已分配人员
   ```
   - ❌ 系统自动阻止重复分配
   - ✅ 保证数据一致性

## 🔍 查看分配结果

### 方式 1：可视化分配页面
- **已分配人员**表格显示所有有项目的人员
- 可以看到员工 A 在项目 X 和 Y 都有记录

### 方式 2：人员列表页面

- 进入"人员分配管理"
- 查看完整的分配历史记录

## 💡 常见问题

### Q1: 一个人的主要项目是什么？
**A:** `Personnel.project` 字段表示当前主要归属项目，用于快速查询和显示。

### Q2: 如何查看某人参与了哪些项目？
**A:** 
```python
from eims_app.models import PersonnelAllocation

personnel = Personnel.objects.get(pk=1)
projects = PersonnelAllocation.objects.filter(
    personnel=personnel,
    allocation_status='allocated'
)
# 返回该员工在所有项目的分配记录
```

### Q3: 如何查看某项目有哪些人？
**A:**
```python
from eims_app.models import PersonnelAllocation

allocations = PersonnelAllocation.objects.filter(
    to_project__project_code='PRJ2026001',
    allocation_status='allocated'
)
# 返回该项目的所有人员分配记录
```

### Q4: 员工从项目 X 调到项目 Y 怎么处理？
**A:**
1. 创建新的 PersonnelAllocation 记录（to_project=Y, from_project=X）
2. 更新 Personnel.main_project = 项目 Y（可选）
3. 原分配记录保留作为历史记录

### Q5: 支持同时分配到多少个项目？
**A:** 理论上没有限制，但建议根据实际工作能力合理安排。

## 🎯 最佳实践

1. **合理设置主要项目**
   - 将工作时间最长的项目设为主项目
   - 便于统计和管理

2. **及时更新分配状态**
   - 项目结束时，更新 `allocation_status`
   - 保持数据准确性

3. **使用部门字段**
   - 填写具体的分配部门
   - 便于跨项目人员统计

4. **定期审查**
   - 检查一人多项目的合理性
   - 避免过度兼职影响工作质量
