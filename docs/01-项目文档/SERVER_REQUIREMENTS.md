## 🌐 带宽选择建议

### 带宽计算

**页面大小估算**：
- HTML：50KB
- CSS：100KB
- JavaScript：200KB
- 图片：500KB
- **合计**：约 850KB/页面

**并发需求**：
```
假设 50 人同时在线，每人每秒访问 1 次：
所需带宽 = 850KB × 50 = 42,500KB/s ≈ 340Mbps

但实际不会所有人同时访问，按 10% 并发计算：
实际带宽 = 340Mbps × 10% = 34Mbps
```

### 带宽方案

#### **方案 A：按固定带宽计费（推荐初期）**
```
2-3Mbps：适合 < 50 用户
3-5Mbps：适合 50-200 用户
5-10Mbps：适合 200-500 用户
```

**成本**：
- 阿里云：¥20/Mbps/月起
- 腾讯云：¥20/Mbps/月起

**优点**：
- 费用可控
- 适合流量稳定的场景

---

#### **方案 B：按使用流量计费（推荐中后期）**
```
单价：¥0.2-0.8/GB（不同地区不同）
峰值带宽：可达 100Mbps+
```

**适用**：
- 流量波动大
- 有突发流量
- 日均流量 < 10GB

**成本对比**：
```
每天 10GB 流量：
按月计费 5Mbps：¥100/月
按量计费 10GB/天：10GB × 30 天 × ¥0.48/GB = ¥144/月
```

## 🆘 常见问题解答

### Q1：能否先低配后升级？
**答**：完全可以！云服务器支持随时升级配置。建议初期选择标准配置，后续根据实际使用情况调整。

### Q2：数据库用 SQLite 还是 MySQL？
**答**：
- 个人项目/测试：SQLite
- 生产环境/企业使用：MySQL 或 PostgreSQL

### Q3：带宽选多大合适？
**答**：
- < 50 用户：2-3Mbps
- 50-200 用户：3-5Mbps
- 200-500 用户：5-10Mbps

### Q4：需要单独购买数据库吗？
**答**：
- 初期：可以和应用程序在同一台服务器
- 中后期：建议使用云数据库 RDS（更稳定、易维护）

### Q5：对象存储必须吗？
**答**：
- 文件较少（< 50GB）：可以本地存储
- 文件较多：强烈建议使用对象存储（更便宜、更安全）
