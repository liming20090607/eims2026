# 🔬 导入深度诊断工具 - 使用指南

## 📋 问题背景

**你的问题**：为什么调试工具显示"全部字段已匹配"，但导入还是失败？

**原因分析**：
1. ✅ **字段匹配** ≠ **数据有效**
2. ✅ **表头正确** ≠ **内容正确**
3. ✅ **格式对齐** ≠ **符合约束**

---

## ✨ 增强版调试工具功能

现在调试工具不仅检查字段匹配，还会进行：

### **1. 字段匹配检查（基础）**
- ✅ 检查 Excel 表头是否与数据库字段对应
- ✅ 提供未匹配字段的修改建议

### **2. 数据质量验证（新增）**
- ❌ **必填字段检查** - 5 个必填字段是否为空
- ⚠️ **日期格式检查** - 是否符合 YYYY-MM-DD
- ⚠️ **金额格式检查** - 是否为有效数字
- ⚠️ **选择字段检查** - 值是否在允许范围内

### **3. 模拟导入测试（新增）**
- 🧪 尝试创建 Django 对象（不保存）
- 🧪 执行完整的数据验证
- 🧪 检测数据库约束冲突

## 🎯 使用场景

### **场景 1：字段匹配成功但导入失败**

**症状**：
```
调试工具显示：✅ 所有字段都已正确匹配
实际导入结果：❌ 导入失败，提示错误
```

**使用新工具诊断**：
1. 访问调试工具
2. 上传 Excel 文件
3. 查看"数据质量验证"部分
4. 查看"模拟导入测试"部分

**可能发现的问题**：
```
❌ 严重错误：
- 第 2 行：缺少必填字段 [project_code]
- 第 3 行：数据重复 - UNIQUE constraint failed: project_code

⚠️ 警告：
- 第 2 行：日期字段 [signing_date] 格式不正确：2026/1/15
- 第 3 行：选择字段 [contract_status] 的值 '进行中' 不在允许范围内
```

**症状**：
```

```

**诊断步骤**：
1. 使用调试工具的"模拟导入测试"
2. 系统会尝试创建对象并执行完整验证
3. 显示具体的数据库级错误


## 💡 常见错误及解决方案

### **错误 1：UNIQUE constraint failed**

**症状**：
```
第 X 行：数据重复 - UNIQUE constraint failed: 
eims_app_projectdetail.project_code
```

**原因**：
- 项目编号/合同编号等唯一字段与数据库中的现有记录重复

**解决方案**：
1. 查询数据库中已存在的编号
2. 修改 Excel 中的编号为唯一值
3. 或者先删除数据库中的重复记录

### **错误 2：NOT NULL constraint failed**

**症状**：
```
第 X 行：缺少必填字段 - NOT NULL constraint failed: 
eims_app_projectdetail.project_name
```

**原因**：
- 必填字段为空或 Excel 单元格为空

**解决方案**：
1. 检查 Excel 中该字段对应的列是否有值
2. 确保必填字段不为空：
   - 项目编号
   - 合同编号
   - 项目名称
   - 合同甲方
   - 合同乙方

### **错误 3：Value is not a valid choice**

**症状**：
```
第 X 行：字段值不在允许范围内
Value '建设中' is not a valid choice.
```

**原因**：
- 选择字段的值不在预定义选项中

**解决方案**：
1. 检查字段的允许值列表：
   ```python
   contract_category: 工程监理/造价咨询/检测/全过程咨询
   project_status: 未开工/在施工/已完工/在停工
   contract_status: 待审核/在执行/已终止/已解除
   settlement_status: 未结算/已结算
   construction_permit_status: 已完成/未完成
   entry_notice: 有/无
   ```
2. 修改为允许的取值

### **错误 4：日期格式不正确**

**症状**：
```
第 X 行：日期字段 [signing_date] 格式可能不正确：2026/1/15
```

**原因**：
- Excel 中的日期格式不是标准的 YYYY-MM-DD

**解决方案**：
1. 在 Excel 中设置单元格格式为 "yyyy-mm-dd"
2. 或者手动修改为标准格式：
   - ❌ 2026/1/15 → ✅ 2026-01-15
   - ❌ 2026.01.15 → ✅ 2026-01-15
   - ❌ 2026 年 1 月 15 日 → ✅ 2026-01-15

### **错误 5：金额字段包含非数字字符**

**症状**：
```
第 X 行：金额字段 [contract_amount] 可能不是有效数字：¥1,000,000
```

**原因**：
- 金额字段包含了货币符号、千分位分隔符等

**解决方案**：
1. 使用纯数字格式：
   - ❌ ¥1,000,000 → ✅ 1000000.00
   - ❌ 1,000,000 元 → ✅ 1000000.00
   - ❌ 一百万 → ✅ 1000000.00
2. 可以在 Excel 中使用公式清除特殊字符
