# 项目详情页布局优化说明

## 优化日期
2026-03-21

## 优化目标
解决页面上部布局不合理、版面未充分利用、右侧空白过多的问题。

## 主要改进

### 1. 字段分类分组
将项目信息按业务逻辑分为 4 个主要组别，每组使用独立的卡片容器：

#### (1) 项目基本信息组
- **合同信息**：项目编号、合同编号、签订日期、合同类别、项目状态、合同状态
- **合同双方**：合同甲方、合同乙方

#### (2) 资金与结算组
- **合同金额**：合同总价、累计回款、合同余款、结算情况
- **项目属性**：项目规模、项目总投资、项目地址
- **备注**：备注信息

#### (3) 服务周期与进度组
- **服务周期**：服务开始时间、服务周期、服务到期时间
- **进场与开工**：进场通知、计划开工日期、实际开工日期、预计竣工日期
- **延期管理**：延期约定、实际延期情况、报建情况

#### (4) 人员与文档组
- **项目人员**：项目总监、现场负责人、联系电话、约定人员配备
- **文档信息**：合同文本、施工许可证、进场通知书（带下载链接）

### 2. 网格布局优化

#### 主布局 (2 列)
```css
.info-grid-main {
    grid-template-columns: repeat(2, 1fr);
}
```
用于：项目基本信息组、人员与文档组

#### 次级布局 (3 列)
```css
.info-grid-sub {
    grid-template-columns: repeat(3, 1fr);
}
```
用于：资金与结算组、服务周期与进度组

#### 响应式设计
- **大屏幕 (>1200px)**: 主布局 2 列，次级布局 3 列
- **中屏幕 (768px-1200px)**: 主布局 1 列，次级布局 2 列
- **小屏幕 (<768px)**: 所有布局均为 1 列

### 3. 视觉样式提升

#### 卡片组容器
- 浅灰色背景 (`#f8f9fa`)
- 圆角边框 (8px)
- 内边距 (20px)
- 蓝色标题栏（带图标）

#### 信息卡片
- 白色背景（与组容器形成对比）
- 左侧蓝色边框 (4px)
- 轻微阴影效果
- Hover 动画（上浮 + 阴影加深）
- 内边距增加至 18px

#### 信息行优化
- 标签宽度从 140px 缩减至 120px（为内容留出更多空间）
- 行间距从 10px 增加至 12px
- 分隔线颜色变浅（`#f8f9fa`）
- 支持长文本自动换行（`word-break: break-word`）

#### 卡片标题
- 字体大小增加至 15px
- 底部添加分隔线（2px solid `#e9ecef`）
- 增加下边距至 15px

## 布局优势

### 空间利用率提升
- ✅ 消除右侧大面积空白
- ✅ 卡片并排显示，充分利用横向空间
- ✅ 响应式布局适配不同屏幕尺寸

### 信息组织更清晰
- ✅ 按业务逻辑分组，便于查找
- ✅ 视觉层次分明，阅读体验好
- ✅ 相关字段集中展示，逻辑性强

### 用户体验优化
- ✅ 分组标题带图标，直观易懂
- ✅ 卡片 Hover 效果，交互反馈好
- ✅ 文档下载按钮直接展示，操作便捷

## 文件修改
- `eims_app/templates/project_ledger/detail.html`
  - CSS 样式部分：新增 `.info-grid-main`、`.info-grid-sub`、`.card-group-container` 等样式
  - HTML 结构部分：重新组织为 4 个卡片组，每组包含 2-3 个信息卡片

## 技术实现

### CSS Grid 布局
```css
/* 主布局 - 2 列 */
.info-grid-main {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 20px;
}

/* 次级布局 - 3 列 */
.info-grid-sub {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
```

### 响应式断点
```css
/* 中等屏幕 */
@media (max-width: 1200px) {
    .info-grid-main {
        grid-template-columns: 1fr;
    }
    .info-grid-sub {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* 小屏幕 */
@media (max-width: 768px) {
    .info-grid-main,
    .info-grid-sub {
        grid-template-columns: 1fr;
    }
}
```
