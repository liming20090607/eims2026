# 多租户登录和公司选择功能增强

## 📋 更新概述

本次更新增强了多租户系统的登录和公司选择功能，提供更安全、更便捷的用户体验。

## ✨ 新功能

### 1. 登录页面公司选择

**功能描述：**
- 用户登录时输入用户名/姓名和密码
- 系统自动识别用户所属的公司
- 根据用户所属公司数量，智能处理：
  - **0家公司**：提示联系管理员
  - **1家公司**：自动选择并登录
  - **多家公司**：显示公司选择下拉列表

**用户体验流程：**

```
用户输入用户名和密码
    ↓
系统验证身份
    ↓
检查用户所属公司数量
    ├─ 0家 → ❌ 提示"您还没有被分配到任何公司，请联系管理员"
    ├─ 1家 → ✅ 自动选择该公司，直接登录成功
    └─ 多家 → 显示公司选择界面
                ↓
          用户从下拉列表选择公司
                ↓
          点击"进入系统"
                ↓
          ✅ 登录成功
```

### 2. 公司切换密码验证

**功能描述：**
- 用户在系统内切换公司时需要输入密码验证
- 超级管理员无需密码（方便管理）
- 普通用户必须输入正确的登录密码

**安全机制：**
- 防止未授权访问其他公司数据
- 保护敏感业务信息
- 符合企业安全规范

**两种切换方式：**

#### 方式1：侧边栏快速切换
```
点击侧边栏"切换公司"按钮
    ↓
弹出密码验证对话框
    ↓
输入登录密码
    ↓
验证通过 → 跳转到公司选择页面
```

#### 方式2：公司选择页面
```
访问 /tenant/select/
    ↓
显示所有可访问的公司卡片
    ↓
选择目标公司
    ↓
输入登录密码
    ↓
点击"确认选择"
    ↓
验证通过 → 切换到新公司
```

## 🔐 安全特性

1. **密码加密验证**
   - 使用Django内置的`check_password()`方法
   - 支持PBKDF2、bcrypt等多种哈希算法
   - 密码不会明文传输或存储

2. **会话保护**
   - 只有验证通过后才更新session中的tenant_id
   - CSRF保护防止跨站请求伪造

3. **权限检查**
   - 验证用户是否有权限访问目标公司
   - 超级管理员特殊处理

4. **数据隔离**
   - 每个查询都应用租户过滤
   - 防止数据泄露

## 💡 使用说明

### 首次登录

1. 访问登录页面 `/login/`
2. 输入用户名/姓名和密码
3. 如果属于多家公司，从下拉列表选择
4. 点击"进入系统"

### 切换公司

**方法1：侧边栏快速切换**
1. 点击侧边栏的"切换公司"按钮
2. 在弹出的对话框中输入密码
3. 点击"确认切换"
4. 在公司选择页面选择目标公司
5. 再次输入密码确认

**方法2：直接访问选择页面**
1. 访问 `/tenant/select/`
2. 选择目标公司
3. 输入密码
4. 点击"确认选择"

### 超级管理员

- 可以看到所有公司
- 切换公司时无需密码验证
- 方便进行系统管理和维护

## 🎯 解决的问题

### 问题1：丙公司显示甲公司数据
**原因：** Session中保存的是甲公司的tenant_id
**解决：** 
- 清除浏览器cookie和session
- 重新登录并选择丙公司
- 系统会自动设置正确的tenant_id

### 问题2：登录时无法选择公司
**解决：** 
- 新增自定义登录视图
- 支持多公司任职用户选择
- 单公司用户自动登录

### 问题3：随意切换公司存在安全风险
**解决：**
- 添加密码验证机制
- 防止未授权访问
- 符合企业安全规范

## 📝 注意事项

1. **Session清理**
   - 如果切换公司后数据不正确，请清除浏览器cookie
   - 或者退出登录后重新登录

2. **用户分配**
   - 新用户需要在UserProfile中分配公司
   - 使用Django Admin或脚本进行分配

3. **密码策略**
   - 建议使用强密码
   - 定期更换密码
   - 不要与他人共享密码

4. **超级管理员**
   - 谨慎使用超级管理员账号
   - 仅用于系统管理和维护
   - 日常操作使用普通账号
