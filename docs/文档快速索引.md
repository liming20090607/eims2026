## 🔧 文档维护

### 新增文档规范
1. **命名格式**: `功能模块_操作类型_日期.md`
   - 例：`CONTRACT_APPROVAL_20260326.md`
   
2. **存放位置**: 根据内容类型放到对应分类目录

3. **文档头部**: 添加元信息
   ```markdown
   # 标题
   
   **创建时间**: 2026-03-26
   **最后更新**: 2026-03-26
   **分类**: 功能实现/问题修复/优化记录
   **相关模块**: 合同管理、人员管理
   ```

### 定期维护
- **每月**: 整理新文档到正确分类
- **每季度**: 清理过时文档
- **每半年**: 更新文档索引

## 💡 使用技巧

### 1. 快速定位文档
```powershell
# 按关键词搜索
Get-ChildItem -Recurse -Filter "*.md" | Select-String "合同审批"

# 按文件名搜索
Get-ChildItem -Recurse -Filter "*CONTRACT*.md"

# 查看最近修改的文档
Get-ChildItem -Recurse -Filter "*.md" | Sort-Object LastWriteTime -Descending | Select-Object -First 10
```

### 2. 使用 VS Code 搜索
- `Ctrl+Shift+F` 全局搜索
- 使用正则表达式提高精度
- 按文件类型过滤

### 3. 查看文档结构
```powershell
# 查看目录树
tree /F docs
```
