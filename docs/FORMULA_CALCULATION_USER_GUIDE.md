# 公式计算功能 - 用户指南

## 🎯 功能概述

现在您可以在任何数值输入框中输入数学公式，系统会自动计算结果！

## 📝 支持的公式格式

### 1. 直接输入算式（推荐）
```
输入：3+2
结果：5.00
```

### 2. Excel 风格（带等号）
```
输入：=3+2
结果：5.00
```

### 3. 乘法
```
输入：10*5
结果：50.00
```

### 4. 除法
```
输入：100/4
结果：25.00
```

### 5. 百分数（特别有用！）
```
输入：100*30%
结果：30.00

输入：50000*12%
结果：6000.00
```

### 6. 混合运算
```
输入：100+50*0.3
结果：115.00
```

### 7. 带括号
```
输入：(3+2)*10
结果：50.00

输入：(100+50)/3
结果：50.00
```

## ⚡ 触发计算的三种方式

### 方式 1：实时计算（新增！）✨
- **操作**：在输入框中输入公式
- **效果**：
  - 输入时输入框会变成**绿色背景**
  - 停止输入后 0.5 秒自动计算
  - 计算完成后自动替换为结果

**示例**：
```
1. 输入：100*30%
2. 输入框变绿色（提示检测到公式）
3. 停止输入 0.5 秒后
4. 自动变为：30.00
```

### 方式 2：按 Enter 键
- **操作**：输入公式后按 `Enter` 键
- **效果**：
  - 立即计算公式
  - 自动跳转到下一个输入框
  - 自动选中下一个输入框的内容

**示例**：
```
1. 输入：5000+3000
2. 按 Enter
3. 变为：8000.00
4. 焦点跳到下一个输入框
```

### 方式 3：失去焦点时
- **操作**：输入公式后点击其他地方（或用 Tab 切换到其他字段）
- **效果**：输入框失去焦点时自动计算

**示例**：
```
1. 输入：10*5
2. 用鼠标点击其他输入框
3. 原输入框变为：50.00
```

## 🎨 视觉提示

### 绿色背景 = 检测到公式
当输入框变成淡绿色时，表示系统检测到公式并准备计算。

### 鼠标悬停提示
将鼠标悬停在输入框上，会显示提示：
```
支持公式计算，例如：3+2, =10*5, (3+2)*10, 100*30%
```

## 🔍 调试方法

1. 按 `F12` 打开浏览器开发者工具
2. 切换到 **Console** 标签
3. 输入公式并按 Enter
4. 查看日志：
   ```

   ```

### 检查功能是否加载
1. 按 `F12` 打开开发者工具
2. 在 Console 输入：
   ```javascript
   window.formulaCalculation
   ```
3. 应该看到对象信息，表示功能已加载

### 检查输入框是否初始化
1. 按 `F12` 打开开发者工具
2. 右键点击任意数值输入框
3. 选择 "Inspect"（检查）
4. 查看 Elements 面板，输入框应该有属性：
   ```html
   data-formula-initialized="true"
   ```

## ⚠️ 注意事项

### 支持的运算符
- ✅ 加法：`+`
- ✅ 减法：`-`
- ✅ 乘法：`*`
- ✅ 除法：`/`
- ✅ 百分号：`%`
- ✅ 括号：`()`
- ✅ 小数点：`.`

### 不支持的格式
- ❌ 字母变量：`a+b`
- ❌ 函数：`sin(30)`, `sqrt(100)`
- ❌ 幂运算：`2^3`（请使用 `2*2*2`）
- ❌ 科学计数法：`1e5`
- ❌ 中文数字：`一百 + 五十`

### 精度说明
- 所有计算结果保留 **2 位小数**
- 符合财务精度要求
- 四舍五入规则

### 错误处理
如果公式无效：
- 输入框会保持原样
- 不会转换为数字
- 控制台会显示警告
- 不影响表单提交

##  常见问题

### Q1: 为什么输入后没有反应？
**A**: 可能的原因：
1. 浏览器缓存了旧版本 → 按 `Ctrl+F5` 强制刷新
2. 没有正确识别为数值输入框 → 检查是否有 `step` 属性
3. JavaScript 未加载 → 查看控制台是否有错误

### Q2: 为什么计算结果不对？
**A**: 检查：
1. 公式是否正确（使用 `*` 表示乘法，不是 `x`）
2. 是否包含不支持的字符
3. 查看控制台日志确认计算过程

### Q3: 可以输入负数吗？
**A**: 可以！例如：
- `-100+50` → `-50.00`
- `100-(-50)` → `150.00`

### Q4: 小数点怎么处理？
**A**: 完全支持：
- `10.5+2.3` → `12.80`
- `100*0.15` → `15.00`

### Q5: 可以在哪些页面使用？
**A**: 所有包含数值输入框的页面：
- 产值回款添加/编辑页面
- 月度报告填报页面
- 项目 Ledger 添加/编辑页面
