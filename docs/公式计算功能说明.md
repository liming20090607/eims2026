# 数值输入框公式计算功能

## 📋 功能概述

在数值型输入框中输入数学公式，系统自动计算并填入结果，提高数据录入效率。

## ✨ 功能特性

### 1. 支持的公式格式

| 公式类型 | 示例 | 结果 | 说明 |
|---------|------|------|------|
| **加法** | `3+2` | `5.00` | 直接输入算式 |
| **带等号** | `=3+2` | `5.00` | 类似 Excel |
| **乘法** | `10*5` | `50.00` | 星号表示乘 |
| **除法** | `100/4` | `25.00` | 斜杠表示除 |
| **混合运算** | `10-3+2` | `9.00` | 从左到右计算 |
| **带括号** | `(3+2)*10` | `50.00` | 括号优先 |
| **百分比** | `100*30%` | `30.00` | 自动处理% |
| **小数** | `10.5*2` | `21.00` | 支持小数 |

### 2. 自动触发时机

- ✅ **按下 Enter 键** - 计算并跳到下一个输入框
- ✅ **失去焦点** - 鼠标点击其他地方时
- ✅ **自动格式化** - 结果保留 2 位小数

### 3. 安全性保证

- ✅ **只允许数学运算** - 过滤所有非数学字符
- ✅ **安全的计算引擎** - 使用 Function 构造函数而非 eval
- ✅ **输入验证** - 多重验证防止恶意代码
- ✅ **错误处理** - 无效公式不会破坏页面

## 🎯 使用场景

### 场景 1：产值回款计算

**问题：** 合同金额 100 万元，收款比例 30%，计算应收金额

**传统方式：**
1. 打开计算器
2. 计算 100 * 30% = 30
3. 手动输入 30

**使用公式计算：**
1. 在输入框直接输入 `100*30%`
2. 按 Enter
3. 自动填入 `30.00` ✅

### 场景 2：多人分摊费用

**问题：** 总费用 5000 元，5 个人分摊

**使用公式：**
- 输入 `5000/5`
- 自动计算 `1000.00`

### 场景 3：复杂计算

**问题：** 计算 (100 + 50) * 0.8 - 20

**使用公式：**
- 输入 `(100+50)*0.8-20`
- 自动计算 `100.00`

## 📖 使用方法

### 方法 1：直接输入

1. 在数值输入框中输入公式
2. 按 **Enter** 键
3. 结果自动填入，焦点跳到下一个输入框

### 方法 2：类似 Excel

1. 输入 `=` 开头（像 Excel 一样）
2. 输入公式，如 `=100*30%`
3. 按 **Enter** 或点击其他地方

### 方法 3：自动触发

1. 输入公式
2. 点击输入框外部（失去焦点）
3. 自动计算并填入结果

### 核心功能

```javascript
// 1. 安全计算函数
function safeCalculate(expression) {
    // 只保留数学字符：数字、运算符、括号、小数点
    let cleanExpr = expression.replace(/[^0-9+\-*/().\s]/g, '');
    
    // 使用 Function 构造函数安全计算
    const result = new Function('return ' + cleanExpr)();
    
    return result;
}

// 2. 格式化结果（2 位小数）
function formatResult(value) {
    return Number(value.toFixed(2)).toString();
}

// 3. 自动初始化所有数值输入框
function initializeFormulaInputs() {
    const inputs = document.querySelectorAll('input[type="number"], input[step]');
    
    inputs.forEach(input => {
        // 监听失去焦点
        input.addEventListener('blur', () => handleFormula(input));
        
        // 监听 Enter 键
        input.addEventListener('keydown', (e) => {
            if (e.key === 'Enter') {
                handleFormula(input);
                // 跳到下一个输入框
                focusNextInput(input);
            }
        });
    });
}
```

## ⚠️ 注意事项

### 1. 支持的运算符

- ✅ `+` 加法
- ✅ `-` 减法
- ✅ `*` 乘法
- ✅ `/` 除法
- ✅ `()` 括号
- ✅ `.` 小数点
- ✅ `%` 百分比（自动转换为 /100）

### 2. 不支持的运算

- ❌ 幂运算（如 `2^3`）
- ❌ 开方（如 `sqrt(4)`）
- ❌ 三角函数
- ❌ 变量引用

### 3. 精度控制

- 所有结果自动保留 **2 位小数**
- 使用四舍五入
- 适合金额计算
