🎯 下一步：部署到服务器
-------------------------------------
1. Git 初始化
   git init
   git add .
   git commit -m "生产部署"

2. 上传到服务器（选择一种）
   - Git: 推送到 GitHub/Gitee
   - SCP: scp -r E:\EIMS2026 root@服务器 IP:/home/
   - FTP: 使用 FileZilla

3. 服务器配置
   - 创建 MySQL 数据库
   - 安装依赖：pip install -r requirements.txt
   - 迁移数据库：python manage.py migrate
   - 收集静态文件：python manage.py collectstatic
   - 配置 Gunicorn + Nginx
