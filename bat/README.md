## ⚙️ 配置说明

### **部署脚本配置**

部分部署脚本需要配置服务器信息。打开脚本后找到以下行并修改：

```batch
set SERVER_IP=你的服务器 IP        ← 修改为实际 IP
set SERVER_USER=root              ← 一般不需要修改
set SERVER_PATH=/var/www/eims     ← 服务器路径
```

### **SSH 密码**

大部分部署脚本会提示输入密码。请使用服务器的 `root` 用户密码。

## 🐛 常见问题

### **Q1: 双击脚本后闪退？**

**A**: 可能是路径问题。尝试：
```cmd
1. 打开命令提示符
2. cd E:\EIMS2026
3. call bat\脚本名称.bat
```

---

### **Q2: 提示"找不到文件"？**

**A**: 检查文件是否在正确的目录：
```
确认路径：E:\EIMS2026\bat\脚本名称.bat
```

---

### **Q3: 部署失败？**

**A**: 检查以下几点：
1. ✅ 服务器 IP 是否正确
2. ✅ SSH 是否通畅（测试：`ssh root@服务器 IP`）
3. ✅ 密码是否正确
4. ✅ 服务器磁盘空间是否充足

---

### **Q4: Git 推送失败？**

**A**: 检查：
1. ✅ Git 是否已初始化
2. ✅ 远程仓库是否已配置
3. ✅ 是否有网络连接
4. ✅ GitHub/Gitee 账号权限
