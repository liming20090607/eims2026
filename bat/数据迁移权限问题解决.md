# 数据迁移 - 权限问题解决指南

**问题**: 使用 `admin` 用户登录，但文件在 `/root/` 目录，权限不足  
**解决**: 3 种方案任选其一

---

## 🔍 **当前问题分析**

### **错误信息**

```bash
bash: /root/import_data_fix_encoding.sh: Permission denied
PermissionError: [Errno 13] Permission denied: '/root/department_data.json'
CommandError: No fixture named 'department_data' found.
```

### **原因**

1. ✅ 您使用 `admin` 用户登录（非 root）
2. ✅ 数据文件在 `/root/` 目录（只有 root 可访问）
3. ❌ admin 用户无法读取 /root/ 下的文件

---

## ✅ **解决方案（3 选 1）**

### **方案 1：切换到 root 用户（推荐）** ⭐⭐⭐⭐⭐

#### **最简单直接**

```bash
# 切换到 root 用户
sudo su -

# 输入 admin 用户的密码

# 现在您是 root 用户了
[root@iZ2ze74hagmo3egfxeffrcZ ~]# 

# 执行修复和导入
bash /root/import_data_fix_encoding.sh
```

---

### **方案 2：将文件复制到有权限的目录** ⭐⭐⭐⭐

如果您不想切换用户：

```bash
# 1. 将文件从 /root/ 复制到家目录
sudo cp /root/*.json /home/admin/

# 2. 修改文件所有者
sudo chown admin:admin /home/admin/*.json

# 3. 进入家目录
cd /home/admin

# 4. 修复编码并导入
python3 << 'EOF'
import os
for filepath in ['department_data.json', 'role_data.json']:
    try:
        with open(filepath, 'rb') as f:
            content = f.read().decode('gbk')
        with open(filepath, 'w', encoding='utf-8') as f:
            f.write(content)
        print(f'已修复：{filepath}')
    except Exception as e:
        print(f'错误：{filepath} - {e}')
EOF

# 5. 进入项目目录
cd /var/www/eims

# 6. 激活虚拟环境
source venv/bin/activate

# 7. 导入数据
python manage.py loaddata /home/admin/department_data.json
python manage.py loaddata /home/admin/role_data.json

# 8. 验证
python manage.py shell -c "from eims_app.models import Department, Role; print('部门:', Department.objects.count(), '角色:', Role.objects.count())"
```

### **方案 3：使用 sudo 执行每个命令** ⭐⭐⭐

## 🚀 **推荐执行流程（方案 1）**

### **完整步骤**

```bash
# 第 1 步：切换到 root 用户
sudo su -

# 输入密码后，提示符会变成 [root@...]#

# 第 2 步：检查文件是否存在
ls -la /root/*.json

# 应该看到：
# -rw-r--r-- 1 root root 5590 department_data.json
# -rw-r--r-- 1 root root 1449 role_data.json

# 第 3 步：运行自动修复脚本
bash /root/import_data_fix_encoding.sh

# 等待完成...

# 第 4 步：如果脚本不存在，手动执行
python3 << 'EOF'
import os
for filepath in ['/root/department_data.json', '/root/role_data.json']:
    try:
        with open(filepath, 'rb') as f:
            content = f.read().decode('gbk')
        with open(filepath, 'w', encoding='utf-8') as f:
            f.write(content)
        print(f'已修复：{filepath}')
    except Exception as e:
        print(f'错误：{filepath} - {e}')
EOF

# 第 5 步：导入数据
cd /var/www/eims
source venv/bin/activate
python manage.py loaddata /root/department_data.json
python manage.py loaddata /root/role_data.json

# 第 6 步：验证
python manage.py shell -c "from eims_app.models import Department, Role; print('成功！部门:', Department.objects.count(), '角色:', Role.objects.count())"

# 第 7 步：退出 root
exit
```

## 📋 **快速命令（复制粘贴）**

### **一键切换到 root 并执行**

```bash
sudo su - << 'EOF'
# 修复编码
python3 -c "
import os
for f in ['/root/department_data.json', '/root/role_data.json']:
    open(f,'w',encoding='utf-8').write(open(f,'rb').read().decode('gbk'))
"

# 导入数据
cd /var/www/eims
source venv/bin/activate
python manage.py loaddata /root/department_data.json
python manage.py loaddata /root/role_data.json

# 验证
python manage.py shell -c "from eims_app.models import Department, Role; print('部门:', Department.objects.count(), '角色:', Role.objects.count())"

exit
EOF
```

## ⚠️ **常见问题**

### **Q1: sudo su - 提示密码错误？**

**A**: 确保输入的是当前 admin 用户的密码，不是 root 密码

---

### **Q2: 没有安装 sudo？**

**A**: 直接使用 root 用户登录：

```bash
# 退出当前用户
exit

# 重新 SSH 登录，使用 root 用户
ssh root@39.106.41.239
```

---

### **Q3: 导入后仍然是 0 条数据？**

**A**: 检查 JSON 文件格式：

```bash
# 查看文件内容前几行
head -n 20 /root/department_data.json

# 应该是类似：
# [
#   {
#     "model": "eims_app.department",
#     "pk": 1,
#     "fields": {...}
#   }
# ]
```
