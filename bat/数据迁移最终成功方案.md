- 执行 scp 命令

- 下载 WinSCP: https://winscp.net/
- 连接服务器：39.106.41.239

## 💡 **核心技巧**

### **PowerShell 的 UTF-8 魔法**

```powershell
# PowerShell 的重定向操作符 > 会自动使用 UTF-8 编码
python command > output.json

# 生成的文件就是 UTF-8 格式
# Linux 可以直接读取，无需转换！
```

这就是为什么我们使用 `> department_data.json` 而不是写入文件的原因。
