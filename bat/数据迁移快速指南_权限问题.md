## ⚡ **快速手动方案（无需上传脚本）**

如果不想上传脚本，直接执行这些命令：

```bash
# 1. 切换到 root
sudo su -

# 2. 修复编码
python3 -c "
import os
for f in ['/root/department_data.json', '/root/role_data.json']:
    open(f,'w',encoding='utf-8').write(open(f,'rb').read().decode('gbk'))
"

# 3. 导入数据
cd /var/www/eims
source venv/bin/activate
python manage.py loaddata /root/department_data.json
python manage.py loaddata /root/role_data.json

# 4. 验证
python manage.py shell -c "from eims_app.models import Department, Role; print('成功！部门:', Department.objects.count(), '角色:', Role.objects.count())"
```

## ⚠️ **常见问题**

### **Q1: sudo su - 提示密码错误？**

**A**: 确保输入的是 admin 用户的密码

如果不知道 admin 密码，可以直接用 root 登录：

```bash
# 退出当前用户
exit

# 重新用 root 登录
ssh root@39.106.41.239
```

---

### **Q2: 脚本不存在？**

**A**: 使用 SCP 上传或手动创建

**方法 1**: SCP 上传（本地 PowerShell）
```powershell
scp bat\数据迁移一键修复.sh root@39.106.41.239:/root/
```

**方法 2**: 手动创建（在服务器上）
```bash
sudo su -
cat > /root/数据迁移一键修复.sh << 'EOF'
# （粘贴脚本内容）
EOF
chmod +x /root/数据迁移一键修复.sh
```

---

### **Q3: 导入后仍然是 0 条数据？**

**A**: 检查 JSON 文件是否正确

```bash
# 查看文件内容
head -n 30 /root/department_data.json

# 应该是有效的 JSON 格式
```
