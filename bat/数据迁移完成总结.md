## ⚠️ **重要说明：为什么"角色列表"页面是空的？**

### **原因解释**

您看到的"角色列表"页面显示的是 **DepartmentRole**（部门角色配置），而不是 **Role**（基础角色）。

这是两个不同的概念：

| 表名 | 用途 | 当前状态 |
|------|------|---------|
| **Role** | 基础角色模板定义 | ✅ 已导入 7 条 |
| **DepartmentRole** | 部门 - 用户 - 角色的关联关系 | ⚠️ 空（需要手动配置） |

---

### **类比理解**

- **Role** = "职位头衔"（如：经理、主管、员工）
- **DepartmentRole** = "实际任命"（如：张三担任监理部经理）

您已成功导入了"职位头衔"，但还需要在系统中进行"实际任命"。

## 🔧 **如何配置部门角色（DepartmentRole）**

### **方法 1：通过管理后台添加（推荐）**

1. **登录系统管理后台**
   ```
   http://您的服务器 IP/admin/
   ```

2. **进入"部门角色配置"**
   - 找到 `eims_app` → `Department roles`
   - 点击 "ADD"

3. **填写信息**
   - **所属部门**: 选择部门（如：监理部）
   - **用户**: 选择用户
   - **角色类型**: manager/deputy/supervisor/member/assistant
   - **角色名称**: 自定义（如：工程部经理）
   - **是否主要负责人**: 勾选（如果是该部门的负责人）

### **方法 2：使用 Django Shell 批量添加**

```bash
cd /var/www/eims
source venv/bin/activate

python manage.py shell << 'EOF'
from eims_app.models import Department, DepartmentRole
from django.contrib.auth.models import User

# 示例：为监理部添加一个部门经理角色
dept = Department.objects.get(department_name='监理部')
admin_user = User.objects.get(username='admin')  # 确保有 admin 用户

role = DepartmentRole.objects.create(
    department=dept,
    user=admin_user,
    role_type='manager',
    role_name='监理部经理',
    is_primary=True,
    permissions='view_department,edit_department,delete_personnel'
)

print(f"✓ 已为 {dept.department_name} 添加角色：{role.role_name}")
print(f"  用户：{admin_user.username}")
print(f"  类型：{role.role_type}")

# 查看已添加的所有部门角色
print("\n当前部门角色配置:")
for r in DepartmentRole.objects.all():
    print(f"  - {r.department.department_name} | {r.user.username} | {r.role_name}")
EOF
```

### **方法 3：创建测试数据脚本**

创建 `/root/create_dept_roles.py`：

```python
#!/usr/bin/env python3
import os, sys, django

sys.path.append('/var/www/eims')
os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'settings')
django.setup()

from eims_app.models import Department, DepartmentRole
from django.contrib.auth.models import User

# 获取或创建 admin 用户
admin, created = User.objects.get_or_create(
    username='admin',
    defaults={'is_staff': True, 'is_superuser': True}
)
if created:
    admin.set_password('admin123')
    admin.save()
    print("✓ 创建 admin 用户（密码：admin123）")

# 为每个部门创建一个默认角色
depts = Department.objects.all()
count = 0

for dept in depts:
    # 检查是否已有该部门的角色配置
    exists = DepartmentRole.objects.filter(
        department=dept, 
        user=admin, 
        role_type='manager'
    ).exists()
    
    if not exists:
        DepartmentRole.objects.create(
            department=dept,
            user=admin,
            role_type='manager',
            role_name=f'{dept.department_name}经理',
            is_primary=True,
            permissions='view_all,edit_all,delete_all'
        )
        count += 1
        print(f"✓ 为 {dept.department_name} 添加默认角色配置")

print(f"\n完成！新增 {count} 条部门角色配置")
print(f"当前总数：{DepartmentRole.objects.count()}")
EOF

chmod +x /root/create_dept_roles.py
python3 /root/create_dept_roles.py
```
