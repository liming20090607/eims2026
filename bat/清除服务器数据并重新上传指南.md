## 📊 详细操作说明

### **方法 A: 自动化脚本 (推荐)**

```bash
# Windows 下双击
```

#### 2. 服务器清理和恢复

```bash
# SSH 登录
ssh root@39.106.41.239

```

---

### **方法 B: 手动操作**

#### 1. 导出本地数据

在本地 Windows 命令行:

```bash
cd E:\EIMS2026
call venv\Scripts\activate.bat
python manage.py dumpdata --format json --indent 2 --exclude auth.permission --exclude contenttypes --exclude admin.logentry --exclude sessions > local_backup_full.json
```

#### 2. 上传到服务器

```bash
scp local_backup_full.json root@39.106.41.239:/var/www/eims/
```

#### 3. SSH 登录服务器

```bash
ssh root@39.106.41.239
```

#### 4. 清空服务器数据

```bash
cd /var/www/eims
source venv/bin/activate
python3 manage.py flush --no-input
```

**警告:** 这会删除所有数据，但会保留 admin 用户!

#### 5. 恢复数据

```bash
python3 manage.py loaddata local_backup_full.json
```

#### 6. 验证恢复

```bash
python3 manage.py shell
```

```python
from eims_app import models
from django.contrib.auth.models import User

print('恢复结果:')
print(f'员工：{models.Employee.objects.count()} 条')
print(f'部门：{models.Department.objects.count()} 条')
print(f'项目：{models.Project.objects.count()} 条')
print(f'合同：{models.Contract.objects.count()} 条')
print(f'公告：{models.Notice.objects.count()} 条')
print(f'用户：{User.objects.count()} 条')
```

#### 7. 重启服务

```bash
supervisorctl restart eims
```
