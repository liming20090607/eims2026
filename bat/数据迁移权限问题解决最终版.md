## 🚨 **关键步骤：必须先切换到 root！**

### **错误原因**

```bash
[admin@iZ2ze74hagmo3egfxeffrcZ ~]$ cat > /root/fix_encoding.py
-bash: /root/fix_encoding.py: Permission denied

[admin@iZ2ze74hagmo3egfxeffrcZ ~]$ ls -lh /root/*.json

```

**原因**:

- ❌ `/root/` 目录只有 root 用户能访问
- ✅ 需要先切换到 root 用户

## ✅ **正确的完整流程**

### **第 1 步：切换到 root 用户**

```bash
sudo su -
```

输入密码后，提示符会从 `[admin@...]$` 变成 `[root@...]#`

---

### **第 2 步：创建修复脚本（现在是 root 用户）**

```bash
cat > /root/fix_encoding.py << 'EOF'
#!/usr/bin/env python3
import os
import json

def fix_json(filepath):
    if not os.path.exists(filepath):
        print(f"File not found: {filepath}")
        return False
    
    size = os.path.getsize(filepath)
    if size == 0:
        print(f"File is empty: {filepath}")
        return False
    
    print(f"Processing: {filepath} ({size} bytes)")
    
    backup = filepath + '.backup'
    with open(filepath, 'rb') as f:
        raw = f.read()
    with open(backup, 'wb') as f:
        f.write(raw)
    print(f"Backup created: {backup}")
    
    encodings = [('utf-8-sig', 'UTF-8 BOM'), ('gbk', 'GBK'), ('gb2312', 'GB2312'), ('gb18030', 'GB18030'), ('latin1', 'Latin-1'), ('utf-8', 'UTF-8')]
    
    for enc, desc in encodings:
        try:
            print(f"  Trying {desc} ({enc})...", end=' ')
            content = raw.decode(enc)
            if content.startswith('\ufeff'): content = content[1:]
            data = json.loads(content)
            with open(filepath, 'w', encoding='utf-8') as f:
                json.dump(data, f, indent=2, ensure_ascii=False)
            print(f"SUCCESS! ({os.path.getsize(filepath)} bytes, {len(data)} records)")
            return True
        except Exception as e:
            print(f"Failed: {e}")
            continue
    
    print("All failed! Restoring backup...")
    with open(backup, 'rb') as f: raw = f.read()
    with open(filepath, 'wb') as f: f.write(raw)
    return False

if __name__ == '__main__':
    files = ['/root/department_data.json', '/root/role_data.json']
    success = sum(1 for f in files if fix_json(f))
    print(f"\nCompleted: {success}/{len(files)} files fixed")
EOF

chmod +x /root/fix_encoding.py
```

---

### **第 3 步：运行修复脚本**

