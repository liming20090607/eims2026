### **方法 3：创建专用导出脚本（最可靠）** ⭐⭐⭐⭐⭐

创建 `export_clean_data.py`：

```python
#!/usr/bin/env python
import os, sys, django, json

os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'settings')
django.setup()

from eims_app.models import Department, Role

def export_model(model_class, filename):
    """导出数据为 JSON"""
    print(f"Exporting {model_class.__name__}...")
    
    objects = model_class.objects.all()
    data = []
    
    for obj in objects:
        fields = {}
        for f in obj._meta.fields:
            value = getattr(obj, f.name)
            if f.is_relation and value:
                value = value.pk
            fields[f.name] = value
        
        data.append({
            'model': f'{model_class._meta.app_label}.{model_class._meta.model_name}',
            'pk': obj.pk,
            'fields': fields
        })
    
    # 写入 UTF-8 JSON
    with open(filename, 'w', encoding='utf-8') as f:
        json.dump(data, f, indent=2, ensure_ascii=False)
    
    print(f"✓ Exported {len(data)} records to {filename}")
    return len(data)

if __name__ == '__main__':
    dept_count = export_model(Department, 'department_data.json')
    role_count = export_model(Role, 'role_data.json')
    
    print(f"\nTotal:")
    print(f"  Departments: {dept_count}")
    print(f"  Roles: {role_count}")
    print("\n✅ Export completed!")
```

执行：

## 🚨 **为什么之前的方法失败？**

### **问题分析**

1. ❌ **PowerShell 重定向混入了 stderr**
   ```powershell
   # 错误的方式
   python manage.py dumpdata ... > file.json
   # Django 的调试输出（stderr）也混入了文件
   ```

2. ❌ **文件开头有 BOM 标记**
   ```
   byte 0xff 0xfe = UTF-16 LE BOM
   ```

3. ❌ **中文字符集混乱**
   - Windows 使用 GBK
   - PowerShell 使用 UTF-16
   - Linux 期望 UTF-8

---

### **正确的做法**

✅ **使用 `2>$null` 丢弃 stderr**
```powershell
python manage.py dumpdata ... 2>$null > file.json
```

✅ **或使用 `Out-File -Encoding utf8`**
```powershell
python manage.py dumpdata ... | Out-File -Encoding utf8 file.json
```

✅ **或使用 Python 脚本直接写入 UTF-8**
```python
with open('file.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, indent=2, ensure_ascii=False)
```
