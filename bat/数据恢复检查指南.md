# 📊 数据恢复检查与恢复方案

## 🔍 问题分析

运行数据库迁移后数据"消失",可能的原因:

1. **SQLite 数据库文件位置变化** - 可能使用了新的空数据库
2. **迁移创建了空表** - migrate 创建了表结构但没有数据
3. **数据库配置变更** - settings.py 中的数据库配置指向了不同文件

## 📋 检查步骤

### 方法 1: 快速检查数据状态

在 SSH 中执行:

```bash
cd /var/www/eims
source venv/bin/activate
python3 manage.py shell
```

然后输入:

```python
from eims_app.models import *
from django.contrib.auth.models import User

print('=== 数据统计 ===')
print(f'项目台账：{Project.objects.count()} 条')
print(f'员工花名册：{Employee.objects.count()} 条')
print(f'部门列表：{Department.objects.count()} 条')
print(f'通知公告：{Notice.objects.count()} 条')
print(f'用户数：{User.objects.count()} 条')
```

### 方法 2: 检查数据库文件

```bash
# 查看数据库文件
ls -lh /var/www/eims/*.db
ls -lh /var/www/eims/*.sqlite3
ls -lh /var/www/eims/db.sqlite3

# 查看文件大小和修改时间
find /var/www/eims -name "*.db" -o -name "*.sqlite3" | xargs ls -lh
```

### 方法 3: 检查数据库配置

```bash
cd /var/www/eims
grep -A 10 "DATABASES" settings.py
```

查看 `DATABASES` 配置指向哪个数据库文件。

## 💾 数据恢复方案

### 方案 1: 如果有备份文件

**检查备份目录:**

```bash
# 查看备份文件
ls -lh /var/www/eims/backup/
ls -lh /var/www/eims/backups/
ls -lh /var/backup/eims/

# 查找最近的备份
find /var/www -name "*.json" -o -name "*.sql" | sort -t'-' -k2 -rn | head -10
```

**恢复数据:**

如果找到备份文件 (例如 `backup_20260321.json`):

```bash
cd /var/www/eims
source venv/bin/activate
python3 manage.py loaddata backup_20260321.json
```

### 方案 2: 检查是否有旧数据库文件

```bash
# 查找所有数据库文件
find /var/www -name "*.sqlite3" -o -name "*.db"

# 检查是否有多个数据库文件
ls -lh /var/www/eims/db.sqlite3*
ls -lh /var/www/eims/*.sqlite3.*
```

如果找到旧数据库文件 (比如 `db.sqlite3.old` 或 `db.sqlite3.bak`):

```bash
# 停止服务
supervisorctl stop eims

# 备份当前数据库
cp /var/www/eims/db.sqlite3 /var/www/eims/db.sqlite3.new

# 恢复旧数据库
cp /var/www/eims/db.sqlite3.old /var/www/eims/db.sqlite3

# 重启服务
supervisorctl start eims
```

### 方案 3: 从 Excel 重新导入

**如果数据是通过 Excel 导入的:**

1. 找到原始的 Excel 文件
2. 重新执行导入操作

**检查是否有导入记录:**

```bash
cd /var/www/eims
source venv/bin/activate
python3 manage.py shell
```

```python
# 查看导入日志
from eims_app.models import *
# 查看是否有导入相关的模型
import eims_app.models as models
print([m for m in dir(models) if 'import' in m.lower() or 'excel' in m.lower()])
```

### 方案 4: 检查本地备份

**检查本地 (Windows) 是否有备份:**


## 💡 预防措施

### 恢复数据后，建议:

1. **定期备份数据库**
   ```bash
   # 添加到 crontab
   0 2 * * * cd /var/www/eims && source venv/bin/activate && python3 manage.py dumpdata > /backup/eims_$(date +\%Y\%m\%d).json
   ```

2. **使用 MySQL 数据库** (推荐生产环境)
   - 更可靠
   - 支持事务
   - 易于备份和恢复

3. **启用自动备份**
   - 每天自动备份
   - 保留多个版本
   - 异地备份
