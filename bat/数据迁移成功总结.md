## 🎯 **遇到的问题及解决**

### **问题 1: 文件编码错误**
- ❌ JSON 文件包含 UTF-8 BOM 标记
- ❌ 文件中有 Django 调试输出（"Fixed Python path..."）
- ✅ **解决**: 使用 `force_clean.py` 脚本清理文件，移除 BOM 和非 JSON 内容

### **问题 2: 外键约束冲突**
- ❌ 部门数据引用了不存在的用户 ID（manager_id=24）
- ❌ Django 的 `loaddata` 命令检查外键约束失败
- ✅ **解决**: 使用自定义 Python 脚本直接通过 ORM 导入，自动将无效的 manager 设为 None

## 📝 **经验总结**

### **最佳实践**

1. ✅ **导出时使用正确方法**
   - PowerShell: 使用 `Out-File -Encoding utf8` 或 `2>$null` 重定向
   - 或使用专用 Python 脚本直接导出

2. ✅ **清理文件很重要**
   - 移除 BOM 标记
   - 移除非 JSON 内容（调试输出等）

3. ✅ **处理外键约束**
   - 使用 ORM 直接操作，绕过 Django 的严格检查
   - 或先导入被引用的表（如 auth_user）
