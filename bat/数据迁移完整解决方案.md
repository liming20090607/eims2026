## 🔧 **问题原因**

### **错误信息**

```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xbc in position 447
```

### **为什么会这样？**

| 系统 | 编码方式 | 说明 |
|------|----------|------|
| **Windows** | GBK | 中文字符集 |
| **Linux** | UTF-8 | 国际字符集 |
| **结果** | ❌ 不兼容 | JSON 文件中的中文无法读取 |

### **具体问题**

1. Windows 导出的 JSON 文件使用 **GBK 编码**
2. 包含中文内容（部门名称、角色名称等）
3. Linux 上的 Python 期望 **UTF-8 编码**
4. 无法解码，导致导入失败

### **方法 2：分步执行**

```bash
# 1. SSH 登录

# 2. 创建修复脚本
cat > /tmp/fix_encoding.py << 'EOF'
#!/usr/bin/env python3
import sys
import os

def fix_encoding(filepath):
    """将文件从 GBK 转换为 UTF-8"""
    if not os.path.exists(filepath):
        print(f"文件不存在：{filepath}")
        return False
    
    try:
        # 尝试读取为 GBK
        with open(filepath, 'rb') as f:
            raw_content = f.read()
        
        # 尝试解码为 GBK
        try:
            content = raw_content.decode('gbk')
            
            # 保存为 UTF-8
            with open(filepath, 'w', encoding='utf-8') as f:
                f.write(content)
            
            print(f"✓ 已修复：{filepath}")
            return True
            
        except UnicodeDecodeError:
            # 已经是 UTF-8
            print(f"- 已是 UTF-8: {filepath}")
            return True
                
    except Exception as e:
        print(f"✗ 错误：{filepath} - {e}")
        return False

if __name__ == '__main__':
    files = sys.argv[1:]
    success = sum(1 for f in files if fix_encoding(f))
    print(f"\n处理完成：{success}/{len(files)} 个文件")
EOF

# 3. 运行修复
python3 /tmp/fix_encoding.py /root/department_data.json /root/role_data.json

# 4. 导入数据
cd /var/www/eims
source venv/bin/activate
python manage.py loaddata /root/department_data.json
python manage.py loaddata /root/role_data.json

# 5. 验证
python manage.py shell -c "from eims_app.models import Department, Role; print('部门:', Department.objects.count(), '角色:', Role.objects.count())"
```
