# 🚨 紧急修复 - SQLite 版本问题

## ❌ 当前问题

```
NotSupportedError: SQLite 3.31 or later is required (found 3.26.0).
```

**原因**: 服务器上的 SQLite 版本是 3.26.0，但新版本的 django-import-export 需要 3.31+

---

## ✅ 解决方案 (3 选 1)

### **方法 1: 双击运行脚本 (最简单)**

**文件位置:**
```
E:\EIMS2026\bat\quick-fix-import-export.bat
```

**双击后:**
1. 会提示输入 SSH 密码
2. 自动安装兼容版本
3. 自动重启服务

---

### **方法 2: 复制粘贴 SSH 命令 (最快)**

打开 PowerShell 或 CMD，复制粘贴:

```bash
ssh root@39.106.41.239 "cd /var/www/eims; source venv/bin/activate; pip install django-import-export==2.0.2; find . -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null; supervisorctl restart eims"
```

**执行后会提示输入密码，输入即可 (密码不显示)**

---

### **方法 3: 分步执行 (最直观)**

#### 步骤 1: SSH 登录
```bash
ssh root@39.106.41.239
```

#### 步骤 2: 进入虚拟环境
```bash
cd /var/www/eims
source venv/bin/activate
```

#### 步骤 3: 安装兼容版本
```bash
pip install django-import-export==2.0.2
```

#### 步骤 4: 清除缓存
```bash
find . -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null
```

#### 步骤 5: 重启服务
```bash
supervisorctl restart eims
```
