## 🏆 **方法 1: Django Admin 后台导入 (最推荐!)**

### ✨ 优点
- ✅ **完全可视化** - 网页界面操作
- ✅ **零代码** - 点点鼠标即可
- ✅ **成功率高** - Django 原生支持
- ✅ **即时验证** - 上传后立即看到数据

### 📋 实现步骤

#### 1. 安装导入工具

在服务器上执行:

```bash
ssh root@39.106.41.239
cd /var/www/eims
source venv/bin/activate
pip install django-import-export
```

#### 2. 配置 Admin

修改 `eims_app/admin.py`:

```python
from import_export.admin import ImportExportModelAdmin
from import_export import resources
from .models import Employee, Department, Project, Contract, Notice

# 为员工表添加导入导出功能
class EmployeeResource(resources.ModelResource):
    class Meta:
        model = Employee

class EmployeeAdmin(ImportExportModelAdmin):
    resource_classes = [EmployeeResource]
    list_display = ['name', 'department', 'position', 'entry_date']
    search_fields = ['name', 'department']

# 同样配置其他模型
admin.site.register(Employee, EmployeeAdmin)
```

#### 3. 在 Admin 后台导入

1. 访问 `http://39.106.41.239:8000/admin/`
2. 登录 admin
3. 点击任意模型 (如"员工")
4. 右上角有 **"导入"** 按钮
5. 选择 Excel/CSV 文件
6. 点击上传

**支持格式:** Excel (.xlsx), CSV, JSON

## 💻 **方法 4: VS Code 远程同步 (推荐开发者)**

### ✨ 优点
- ✅ **本地编辑** - 用熟悉的编辑器
- ✅ **一键同步** - 自动上传
- ✅ **版本控制** - Git 集成
- ✅ **实时预览** - 修改立即生效

### 📋 实现步骤

#### 1. 安装 VS Code Remote-SSH

1. 打开 VS Code
2. 安装扩展: `Remote - SSH`
3. 连接服务器:
   ```
   ssh root@39.106.41.239
   ```

#### 2. 配置自动同步

安装扩展: `Syncing`

配置 `settings.json`:
```json
{
  "syncing.gist": "your-gist-id",
  "syncing.uploadOnSave": true
}
```

#### 3. 使用方式

- 本地修改代码/数据
- Ctrl+S 保存
- 自动同步到服务器
- 刷新浏览器查看效果

## 🚀 **方法 5: 自动化部署工具**

### ✨ 优点
- ✅ **一键部署** - 完全自动化
- ✅ **持续集成** - Git push 自动部署
- ✅ **多环境** - 开发/测试/生产
- ✅ **回滚支持** - 快速恢复

### 📋 推荐工具

#### A. GitHub Actions

创建 `.github/workflows/deploy.yml`:

```yaml
name: Deploy to Server

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    
    - name: Upload data to server
      uses: easingthemes/ssh-deploy@v2.1.1
      with:
        SSH_PRIVATE_KEY: ${{ secrets.SSH_KEY }}
        REMOTE_HOST: 39.106.41.239
        REMOTE_USER: root
        SOURCE: "data/"
        TARGET: "/var/www/eims/data/"
```

#### B. Fabric (Python 部署工具)

创建 `fabfile.py`:

```python
from fabric import task

@task
def deploy(c):
    c.put('local_backup_full.json', '/var/www/eims/')
    c.run('cd /var/www/eims && python3 manage.py loaddata local_backup_full.json')
```

执行:
```bash
fab deploy
```
