# 🎉 数据导入 - 超级简单的方法

## 🏆 **最简单方法：Django Admin 后台导入**

### ✨ 特点
- ✅ **完全可视化** - 网页界面，像上传附件一样简单
- ✅ **零代码** - 点鼠标即可，无需命令
- ✅ **支持 Excel** - 直接上传 .xlsx/.csv 文件
- ✅ **成功率高** - 自动校验数据
- ✅ **即时预览** - 上传前可以看到数据

---

## 📋 **3 步完成数据导入**

### **步骤 1: 安装导入工具 (1 分钟)**

双击运行:
```
E:\EIMS2026\bat\install-import-export-tool.bat
```

**或者 SSH 手动执行:**
```bash
ssh root@39.106.41.239
cd /var/www/eims
source venv/bin/activate
pip install django-import-export
```

---

### **步骤 2: 重启服务 (30 秒)**

双击运行:
```
E:\EIMS2026\bat\restart-and-verify.bat
```

**或者 SSH 手动执行:**
```bash
supervisorctl restart eims
```

---

### **步骤 3: 登录后台导入数据 (2 分钟)**

1. **访问:** `http://39.106.41.239:8000/admin/`
2. **登录:** 使用 admin 账号
3. **点击模型:** 如"员工"、"项目"、"合同"等
4. **点击右上角:** **"导入"** 按钮
5. **选择文件:** 从本地选择 Excel/CSV 文件
6. **预览数据:** 确认数据正确
7. **点击提交:** 完成导入!

## 📊 **数据准备指南**

### **Excel 格式要求**

创建 Excel 文件，第一行是字段名:

| 员工编号 | 姓名 | 性别 | 手机号 | 学历 | 民族 | 入职时间 |
|---------|------|------|--------|------|------|----------|
| 001 | 张三 | 男 | 13800138000 | 本科 | 汉族 | 2024-01-01 |
| 002 | 李四 | 女 | 13900139000 | 硕士 | 汉族 | 2024-02-15 |

### **字段对应关系**

**员工表 (Employee):**
- 员工编号 → employee_code
- 姓名 → name
- 性别 → gender
- 手机号 → mobile
- 学历 → education
- 民族 → ethnic
- 入职时间 → entry_time

**项目表 (Project):**
- 项目编号 → project_code
- 项目名称 → project_name
- 项目类别 → project_category
- 项目状态 → project_status
- 项目地址 → project_address
- 现场负责人 → project_manager

## 💡 **常见问题**

### Q1: 安装失败怎么办？

**解决:**
```bash
ssh root@39.106.41.239
cd /var/www/eims
source venv/bin/activate
pip install --upgrade django-import-export
```

### Q2: 找不到"导入"按钮？

**解决:**
1. 确认已安装 `django-import-export`
2. 重启服务 `supervisorctl restart eims`
3. 清除浏览器缓存 (Ctrl+F5)

### Q3: Excel 上传后提示错误？

**检查:**
1. 第一行必须是字段名
2. 字段名要与模型字段对应
3. 日期格式：YYYY-MM-DD
4. 数字不要带单位

### Q4: 数据重复怎么办？

**解决:**
- 导入工具会自动检测重复
- 可以选择"跳过"或"覆盖"
- 建议先导出再导入
